## 一、争议结论

“一个样本最多只能编码4—5个标签”不是定性内容分析的通行硬性上限。编码数量应由研究问题、分析单位和材料复杂度决定；但代码越多、标签越稀有、边界越相似，编码员的认知负担和漏标概率通常越高，一致性也更难维持（O'Connor & Joffe, 2020）。因此，本研究既不把所有维度强制改成单标签，也不把所有逻辑组合另建为新类别。

本轮采用以下原则：

1. **原子判断**：编码员只判断不能由其他字段推出的项目。
2. **真实共现**：信息、评价、建议等可以在同一片段出现的功能分别记录为0/1。
3. **真正互斥**：视觉主体、人数档位、景别等同一测量轴内部保留单选。
4. **零类派生**：`CS-OTH`、`AT-NON`、`IS-NON`不由编码员另行选择；`CS-OTH`和`AT-NON`分别表示未命中对应维度的关注项，不等同于“无实质内容”。
5. **跨维度去重**：`CS-INT`由V5互动信号派生，不在V1重复判断。
6. **不把组合当新类别**：独立Sigmoid不要求训练集覆盖全部`2^K`种组合；若研究特定组合或高阶依赖，仍须检查该组合的实际样本数（Zhang & Zhou, 2014; Read et al., 2011）。

## 二、互斥、共现与派生关系总表

| 维度 | 校订前问题 | 校订后结构 | 关系性质 |
|------|------------|------------|----------|
| V1 内容策略 | “单标签”“允许双标签”并存；CS-INT与V5重复 | `cs_inf/cs_edu/cs_emo`人工0/1；`cs_int`和`cs_oth`派生 | 三个原子项可共现 |
| V2 目的地资源 | 九项同时扫描负担较高；HIS/ARC边界不清 | 自然4项、人文5项分屏；逐项0/1并定位证据；大类派生 | 九项可共现 |
| V3 语言功能 | INF/EVL/SUG强制单选并设优先级，损失复合表达 | `at_has_info/at_has_eval/at_has_sug`人工0/1；`at_non`派生 | 三项可共现 |
| V3 情感方向 | 无人工强度金标，却要求模型输出连续强度 | 人工标POS/NEG/MIX/NEU；`sentiment_val=P(POS)-P(NEG)` | 方向条件单选；连续值派生 |
| V5 互动信号 | QUE/DIR/SOC强制单选 | 三个原子0/1；`is_non`派生 | 三项可共现 |
| V11 视觉主体 | 多主体图片需要主次规则 | 仍为五类单选，以视觉突出度和面积判定 | 真正互斥 |
| V12 视觉呈现 | 场景性质、景别、视角混成五类 | 拆为`scene_context/shot_scale/viewpoint`三个单选子字段 | 子字段间独立，字段内互斥 |
| V14 人物呈现 | 人数与人景互动混成互斥类别 | `people_count`单选 + `human_scene_interaction` 0/1 | 两轴独立 |
| V15 消费符号 | 品牌存在与品牌类型逻辑重叠 | `CS-BRA`为存在性；三种类型可共现并向上派生存在性 | 类型可共现 |

## 三、文本轨边界复核

### 3.1 V1：CS-INF、CS-EDU与CS-EMO

| 标签 | 只判断什么 | 不判断什么 | 例子 |
|------|------------|------------|------|
| CS-INF | 是否提供可用于旅行决策的价格、路线、时间、地点、清单或步骤 | 不把所有事实陈述都视为实用信息 | “地铁3号线到青岛站，人均200元” |
| CS-EDU | 是否解释历史、文化、地理、非遗或地方知识 | 不因出现地名就自动标知识 | “栈桥始建于1892年” |
| CS-EMO | 是否通过感官描写或氛围语言营造体验 | 不把所有好坏评价都视为渲染 | “海风带着咸味，落日把海面染成金色” |

同一片段可同时调用实用信息、知识阐释和情感渲染，不再选择“主要策略”。商业推广不属于V1，统一在帖子级V6记录。

### 3.2 V1与V3的交叉边界

- `CS-INF`是**内容策略**，只覆盖面向旅行决策的实用信息；`AT-INF`是**语言功能**，覆盖任何可核验命题。因此“栈桥始建于1892年”可为`CS-EDU=1, AT-INF=1`。
- `CS-EMO`是感官或氛围渲染；`AT-EVL`是明确价值判断。“海风吹过来很舒服”可以二者共现；“海风带着咸味”可只有CS-EMO；“门票很贵”可只有AT-EVL。
- `CS-INT`不再人工判断，由`IS-QUE/IS-DIR/IS-SOC`的OR结果生成。

这些字段相关并不等于定义重复。试标时应查看经验相关：若两个标签几乎总是同时出现，再检查是否仍具有区分效度。

### 3.3 V2：九个资源亚类

V2保留多标签，因为一个片段可以真实调用多类资源。降低负担的方式不是强制单选，而是：

1. 标注界面先呈现自然资源4项，再呈现人文资源5项；单屏不超过5个判断。
2. 每个阳性标签必须绑定证据词或证据片段，词表只作提醒，不自动定类。
3. `RS-R-HIS`按历史、遗产或年代属性判断；`RS-R-ARC`按住宿、交通、设施或当代使用功能判断。同一对象若两类属性均被明确调用，可以共现。
4. `rs_n`与`rs_r`由Layer 2聚合，不重复人工判断。

### 3.4 V3与V5

- AT-INF、AT-EVL、AT-SUG分别回答“有无事实命题”“有无价值判断”“有无行动建议”，不设优先级。
- 只标文本明确表达，不把“看到了城市全貌”推断成“壮观”，也不把“人很多”自动推断成“热闹”或“拥挤”。
- 情感方向只在片段含评价或建议时人工标注。模型概率派生的`sentiment_val`是净方向分数，不是独立验证过的心理强度。
- IS-QUE、IS-DIR、IS-SOC可以共现。“你们觉得怎么样？喜欢的话记得码住”同时为QUE和DIR。

## 四、视觉轨边界复核

### 4.1 V11视觉主体

V11仍保留五类单选，因为它测量“画面中最主要的可见对象”。多主体时先看视觉突出度，再看面积；面积接近、拼图或遮挡图片须记录低置信度并进入复核集。`VS-PEO`不能以“画面有人”作为充分条件，人物须为主体。

### 4.2 V12视觉呈现方式

原五类不是同一测量轴。例如栈桥可以同时是标志性场景、全景和航拍。拆分后：

- `scene_context`：SC-ICO标志性场景、SC-STR日常场景、SC-OTH其他/不适用；
- `shot_scale`：SS-CLO特写、SS-MID中景、SS-PAN全景；
- `viewpoint`：VP-GRD平视/常规、VP-HIG高位俯视、VP-AER航拍。

标志性场景仍依赖目的地知识。正式编码前应建立山东地标白名单及图例，未在白名单但可能具有代表性的对象标低置信度，不能由编码员随意扩展。

### 4.3 V14人物呈现

人数是可见计数，互动是关系判断，两者不能互斥。`people_count`按0人、1人、2人及以上单选；`human_scene_interaction`只有在人物与目的地元素发生明确接触、操作或面向性交互时为1。创作者身份和人物关系不从单图推断，移至帖子级`creator_appears`。

### 4.4 V15消费符号

品牌存在性与品牌类型存在父子关系。编码员识别清晰可辨的Logo或名称，并判断是否属于住宿、餐饮、交通；三类可以共现。任何类型为1时，程序把`CS-BRA`置为1。普通交通工具但无可识别品牌时，CS-TRA为0。

## 五、仍未由结构改造解决的风险

| 风险 | 影响 | 控制方案 |
|------|------|----------|
| 语义片段切分 | 不同单位会使标签信度不可直接比较 | 编码前固定`seg_id`；试标阶段单独裁决边界 |
| 隐含评价/建议 | 编码员可能把语用推断当文本证据 | 采用“只标明确表达”规则并积累反例 |
| 低频标签 | alpha/kappa和模型召回率不稳定 | 分层/定向抽样；报告阳性数与置信区间 |
| V12标志性场景 | 依赖目的地知识 | 地标白名单、图例和低置信复核 |
| V6隐性商业推广 | 需帖子级语境且判断主观 | 单列显性/隐性证据，报告分项信度 |
| 创作者跨平台分层 | 绝对粉丝阈值的平台可比性有限 | 绝对阈值作主分析，平台内分位数作敏感性分析 |

结构拆分只能提高可操作性，不能预先证明主观性已经下降。最终证据来自试标后的逐标签分歧模式和信度结果。

## 六、500条人工金标的执行方案

### 6.1 试标与冻结

1. 从500条中分层抽取100条，覆盖平台、创作者层级、文本长度、预期稀有标签和典型边界案例。
2. 两位编码员编码相同的固定片段，分别完成V1、V2自然4项、V2人文5项、V3和V5模块。
3. 首轮不协商答案；完成后按标签检查分歧原因、证据位置、标签基数和共现频数。
4. 修订编码簿并冻结版本后，两人重新独立编码这100条，使500条金标使用同一规则版本。

### 6.2 全量信度与裁决

两位编码员对全部500条独立编码。每个原子二值标签分别报告名义尺度Krippendorff's alpha、Cohen's kappa、原始一致率、阳性一致率、阴性一致率及阳性样本数；集合级结果可补充MASI距离版本的alpha（Passonneau, 2006）。项目质量门槛为`alpha >= .80`；`.667-.80`只作暂定使用并须复查，低于`.667`的标签不进入模型训练。

信度计算使用裁决前数据。团队在信度报告完成后依据证据位置和冻结编码簿裁决分歧，形成模型使用的金标。

### 6.3 训练与测试

按`author_id`分组切分，防止同一作者的语言风格同时进入训练集和测试集。500条原则上约350条用于初始训练/开发、约150条预先锁定为测试；切分兼顾平台和稀有标签。测试集不得参与主动学习、阈值选择或调参。若核心稀有标签的测试阳性数不足，应追加定向评估样本，而不是从训练结果中挑选案例。

## 七、对神经网络结构的直接影响

```text
共享文本编码器
  ├── V1：3个原子Sigmoid输出
  ├── V2：9个资源Sigmoid输出
  ├── V3：3个语言功能Sigmoid输出
  ├── V3方向：POS/NEG/MIX/NEU条件分类
  └── V5：3个互动Sigmoid输出

规则层
  ├── cs_int = OR(V5三个输出)
  ├── cs_oth / at_non / is_non = 对应零向量
  ├── rs_n / rs_r = Layer 2 OR聚合
  └── sentiment_val = calibrated P(POS) - P(NEG)
```

模型性能须逐标签报告Precision、Recall、F1和PR-AUC，并给出macro/micro汇总、概率校准、分平台/创作者层级表现及关键SRM/SAM估计量的人工金标—模型差值。Exact Match可以补充，但不应作为多标签任务的唯一指标。

## 八、当前冻结与待试标事项

### 已在v3.3校订版冻结

1. V1、V3、V5不再设置主标签或优先级。
2. `CS-INT`与所有“无/其他”字段由程序派生。
3. V2保留九个可共现资源亚类，并分为4项/5项两个标注模块。
4. V12拆为场景语境、景别、视角；V14拆为人数、互动。
5. 连续`sentiment_val`改为模型概率派生的净方向分数。

### 待试标后决定

1. 哪些标签需进一步合并、删除或增加反例。
2. V12地标白名单和V6隐性商业意图的最终边界。
3. 稀有标签是否需要定向扩样，以及最终训练总量。
4. 哪些共现关系进入推断统计，哪些仅作描述。
5. 是否需要标签依赖模型；在独立Sigmoid基线和样本证据不足前不增加复杂结构。
