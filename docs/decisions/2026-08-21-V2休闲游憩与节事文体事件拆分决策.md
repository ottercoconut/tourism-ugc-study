# V2休闲游憩与节事文体事件拆分决策

- Origin Date: 2026-08-21

## 一、决定

原`RS-R-ACT/rs_r_act`把常态化旅游参与体验与时限性组织事件合并，无法区分“目的地可以持续提供什么体验”与“目的地在特定时间举办什么事件”。自编码表v3.10.0起：

1. 将`RS-R-REC/rs_r_rec`“休闲游憩活动”与`RS-R-EVT/rs_r_evt`“节事与文体事件”设为并列的V2 Layer 2人文资源亚类；
2. 将节事与文体事件细分为`EVT-SPT/evt_spt`体育赛事、`EVT-PER/evt_per`演艺活动、`EVT-FES/evt_fes`节庆会展和`EVT-OTH/evt_oth`其他事件四个Layer 3人工子类；
3. 原`RS-R-ACT/rs_r_act`仅保留为`rs_r_rec OR rs_r_evt`的分析汇总，不再作为人工标签、置信度字段、证据字段或模型输出；
4. v3.9.0及以前的人工`rs_r_act`不能反推新标签，凡进入新版分析的受影响记录必须回到原文重编码。

## 二、核心边界

`REC`与`EVT`按是否依赖特定场次、赛期、节期、展期或届次区分，不按是否收费、是否商业化或是否由企业组织区分。因此，日常游船观光、潜水体验和帆船体验属于`REC`；帆船赛、演唱会和啤酒节属于`EVT`。

事件子类可共现。音乐节可同时命中`EVT-FES`与`EVT-PER`。事件名称本身不自动触发`RS-R-FOL`或`RS-R-GAS`；只有文本直接调用民俗传统、地方仪式、饮食或饮品体验时才并标相应资源。

## 三、方法与工程后果

- V2由2个Layer 1、10个Layer 2及4个Layer 3事件子类组成，共16个人工二元字段；
- `rs_depth`只累加10个Layer 2亚类，不重复累加事件子类或`rs_r_act`；
- 人工Excel模板升至`all-label-manual-coding-v2.4`，文本面删除`rs_r_act`及其置信度列，新增6个字段及其置信度列；
- BERT对16个V2人工字段逐项输出，`rs_r_act`不设训练头；
- 共同校准必须覆盖`REC/EVT`时限边界、事件子类共现及事件与`FOL/GAS/ARC`的并标边界；正式冻结前不得把设计完整性表述为已取得信度证据。

## 四、决定理由

本拆分直接服务于生产端研究：它允许分别比较KOL与KOC如何调用常态游憩、体育赛事、演艺活动和节庆会展来呈现青岛。该结构测量的是UGC中的资源呈现与形象建构方式，不据此推断受众认知或行为效果。
