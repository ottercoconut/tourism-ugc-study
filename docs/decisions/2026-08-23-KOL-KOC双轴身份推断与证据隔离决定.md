# KOL/KOC双轴身份推断与证据隔离决定

> **文档状态**：`SUPERSEDED / HISTORICAL`
> **内部文档版本**：`v1.1`
> **生效日期**：2026-08-23
> **现行上位标准**：[`编码表.md`](../data-dictionary/编码表.md) v3.13.0
> **替代决定**：[`2026-08-24 KOL/KOC型试编码立即启动决策`](./2026-08-24-KOL-KOC型试编码立即启动决策.md)。本文旧CI必要条件、旧角色值及四组件矩阵仅供追溯，不得用于当前试编码。
> **替代记录**：本记录替代[`理论框架收缩与测量边界决策`](2026-08-23-理论框架收缩与测量边界决策.md)中“仅触达规模主比较”的决定。
> **边界**：本文记录的是v3.12.0形成前的过渡设计。`creator_role`现已写入编码表v3.13.0，但旧CI必要条件、旧角色值与四组件矩阵均已失效；当前试编码只能执行替代决定与编码表v3.13.0。

## 一、决定

保留KOL/KOC作为本研究的**作者级主比较构念**，同时将粉丝量保留为独立的`reach_tier`。二者不可互相替代：

`平台账号 × 观察期的作者证据包 → creator_role（KOL/KOC/ORDINARY/HYBRID/UNK）`

`粉丝数快照 → reach_tier（超大/大/中小/小触达规模）`

分析时，以证据充分且裁决完成的KOL与KOC为主比较样本，报告/控制`reach_tier`、平台与明确商业披露；若两角色在规模上没有共同支持，结论仅是“角色—规模组合差异”，不得声称识别了脱离规模的纯角色效应。

## 二、现有采集证据与作者级单位

当前采集界面可见或可关联的作者信息包括平台账号ID、显示名、简介、认证、粉丝量、关注量、主页定位、采集时间，以及同一作者的多个帖子、发布时间和互动字段。这些资料足以启动作者角色试点，但每个字段的实际覆盖率、解析状态和时间差必须在导出前程序化审计。

作者角色单位固定为`platform + author_id + evidence_window`：

- 同一平台同一作者的多个目标帖共享同一次`author_snapshot_id`与角色裁决，不逐帖重复判定；
- 跨平台账号只有在私有、可审计证据充分时才可关联为同一`creator_entity_id`；同名、相似头像或相似简介不得自动合并；
- 作者资料可能随时间变化，故保存`profile_captured_at`、证据窗口起止、帖子发布时间与匹配状态；
- 缺少足够资料时标`UNK`或`evidence_status=INSUFFICIENT`，不得为了完整分组强行归为KOC。

## 三、身份推断规则

| 角色 | 最低证据组合 | 明确不充分的证据 |
|---|---|---|
| `KOL` | 专业/职业/认证/权威等至少一项可审计证据，且有持续领域创作和稳定影响证据 | 单一高粉丝数、单条高互动帖、昵称自称“专家” |
| `KOC` | 持续的消费者或旅行者第一手经验分享、稳定的领域/社群参与，并且没有主导性的专业权威证据 | 粉丝不足一万、未认证、单条攻略或单次消费体验 |
| `ORDINARY` | 仅普通或偶发分享，未达到任一角色的持续性与影响证据 | 粉丝少或互动低本身 |
| `HYBRID` | 专业/权威和消费者经验两类证据都显著 | 仅有模糊的商业合作猜测 |
| `UNK` | 证据不足、时间不匹配或裁决未决 | 不适用 |

每一项角色判断由两名编码员先分别记录以下证据字段，再填写`raw_role_response`：`ev_expert_authority`、`ev_consumer_experience`、`ev_sustained_creation`、`ev_community_influence`、`evidence_status`。裁决前记录不得被覆盖；`creator_role_adjudicated`只在信度计算后产生。

## 四、证据隔离：防止循环定义

| 层 | 允许材料 | 禁止材料 |
|---|---|---|
| T0 作者角色推断 | 作者简介/认证/快照、固定历史窗口内的非目标帖、作者级聚合描述 | 目标帖的V3—V6人工或模型标签、目标帖互动结果、研究假设方向 |
| T1 内容编码与比较 | 冻结的目标帖文本/图像与V3—V11编码 | `creator_role`、粉丝数、认证、作者名、角色模型建议 |
| 关联与统计 | 两条测量分别冻结后，通过`author_snapshot_id`关联 | 用内容结果回写、修正或训练角色金标 |

这样，长篇攻略、专业化措辞或某一帖互动高不会同时成为“身份定义”和“被比较的内容结果”。同一作者多帖既能提供独立的T0历史证据，也会在T1分析中通过作者聚类标准误处理重复观测。

## 五、门槛与后续编码表变更

| 门 | 通过条件 | 未通过时的处理 |
|---|---|---|
| G1 数据门 | 作者字段覆盖率、来源、时间与作者—帖子链接可审计 | `creator_role`不进入主比较，仅保留`reach_tier` |
| G2 人工门 | 证据字段与过程级角色判断在新样本独立盲标中达到预设信度，无持续边界分歧 | 修订规则后换新样本；仍失败则停止角色主分析 |
| G3 样本门 | 经裁决的KOL/KOC均有预注册支持数，并与`reach_tier`存在可解释的共同支持 | KOL/KOC只作探索或回退至规模比较 |
| G4 模型门 | 若扩展角色预测，锁定测试的逐类、平台/时间子群、校准和下游敏感性均通过 | 仅使用人工角色金标，不自动扩展 |

G1—G3通过后，才对`编码表.md`执行一次受控升级：新增作者快照、证据字段、角色原始标注、裁决状态与`creator_role_adjudicated`，并同步更新任务模板、导出/导入、信度与下游分析文档。当前不修改V0—V11内容标签。

## 六、理论边界仍然有效

本决定只恢复“谁是KOL/KOC”的作者级推断，不恢复受众机制推断。即使KOL与KOC在内容表征上存在差异，也不能据此断言来源可信度、准社会关系、意义迁移、情绪感染、访问意向或传播效果已经发生。角色与触达规模解释的是创作者分组，不替代受众端测量。

本次理论依据仍见[`理论收缩证据台账_2026-08-23.md`](../../literature/理论收缩证据台账_2026-08-23.md)，其中Manthiou等关于旅行影响者构念的研究支持“角色不能简化为粉丝数”，而非要求放弃角色研究。
