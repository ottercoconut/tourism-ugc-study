# 理论框架收缩与测量边界决策

> **文档状态**：`HISTORICAL / SUPERSEDED`
> **生效日期**：2026-08-23
> **替代记录**：[`2026-08-23-KOL-KOC双轴身份推断与证据隔离决定.md`](2026-08-23-KOL-KOC双轴身份推断与证据隔离决定.md)
> **现行上位标准**：[`编码表.md`](../data-dictionary/编码表.md) v3.11.0
> **实施范围**：论文的理论解释、题目、研究问题、假设表述、分析命名与参考文献；不改变V0—V11的字段、值域、编码单位或质量门。
> **批准边界**：依据本轮研究负责人授权实施论文层面的收缩。任何V0角色字段或编码值的实质变化，仍须另行更新编码表并完成信度试点。

## 一、背景

当前数据的可观察部分是：V0中的粉丝阈值分组，V1—V2中的帖子情境，以及V3—V6中的文本内容变量。它没有受众调查、实验分组、行为追踪、关系强度、受众感知可信度、传播网络或创作者动机材料。

因此，原先的“创作者身份 → 受众心理机制 → 目的地形象/行为结果”解释链超出了现有测量。尤其是，粉丝阈值不等于KOL/KOC角色，`CS-INT`不等于准社会关系，V5情感表达不等于受众情绪感染，V1未观察到披露也不等于不存在商业合作。

## 二、候选方案与决定

| 方案 | 主张 | 与当前数据的匹配 | 决定 |
|---|---|---|---|
| A. 受众机制模型 | 创作者通过可信度、准社会关系、意义迁移或情绪感染改变受众 | 不匹配；缺少受众与机制测量 | 不作为主理论 |
| B. 生产端内容表征模型 | 比较不同创作者分组在资源、呈现方式、表达与评价属性上的可观察差异 | 匹配V0—V6 | **采用** |
| C. KOL/KOC角色模型 | 比较经独立确认的创作者角色 | 只有完成`reach_tier + creator_role`试点后才匹配 | 保留为未来条件路径 |

**最终决定：** 本研究的正式主链收缩为：

`粉丝阈值定义的触达规模组 + 帖子情境（V1—V2） → 在线目的地内容表征（V3—V6） → 频率、轮廓、条件共现与组间差异`

这是一条“测量—描述—比较”链，不是一条“创作者—受众心理—行为”的因果链。

## 三、术语与变量的唯一解释

| 术语 | 本文中的含义 | 不应推出的含义 |
|---|---|---|
| 在线目的地内容表征 | 创作者帖子中可观察的资源指称、内容呈现方式、语言功能、表达方向与被评价/建议的属性 | 受众完整的目的地形象 |
| 触达规模组 | 按V0粉丝绝对阈值形成的四档分组 | KOL/KOC角色、专业性或可信度 |
| 内容策略（V3） | 成品文本的功能性呈现模式 | 创作者的主观意图、实际互动或传播效能 |
| 情感/评价表达（V5） | 创作者在片段中表达的方向与强度 | 受众的情感状态、情绪感染或态度变化 |
| 属性指向（V6） | 被评价或建议的目的地属性 | 对目的地认知形象的完整测量 |
| 明确商业披露（V1） | 可观察到的披露文本 | 真实商业合作、商业意图或广告效果 |

## 四、理论定位

| 理论/概念 | 本次定位 | 原因 |
|---|---|---|
| 目的地形象的概念化与信息源多元性 | 核心概念边界 | 用于区分信息材料、在线表征与受众实际形象 |
| 社媒目的地内容中的资源、认知/情感属性与参与主体 | 核心分析参照 | 直接支持生产端内容的结构化描述与比较 |
| 影响者内容分析 | 相邻实证参照 | 支持“影响者帖子可被分析”，不支持“首次研究” |
| KOL/KOC角色 | 暂缓构念 | 当前仅有粉丝阈值，尚无独立角色测量 |
| 意义迁移、准社会关系、来源可信度、ELM、情绪感染 | 背景/未来受众研究 | 需要本研究未测量的中介、心理或行为结果 |
| 共同创造、传播效果、访问意向 | 不进入本研究结论 | 当前没有互动过程、效果或意向数据 |

## 五、允许结论与禁止结论

| 可以在结果中说 | 不可以在结果中说 |
|---|---|
| 某触达规模组的资源调用、呈现方式或评价性表征比例不同 | 某KOL/KOC角色本质上更专业、真实或可信 |
| 某些变量在同一片段中条件共现 | 某内容策略导致资源调用、说服或受众形象改变 |
| 帖文出现互动邀请、积极/消极表达或明确披露 | 形成准社会关系、引发情绪感染或存在实际商业合作 |
| 文本与视觉在通过质量门后存在对应关系 | 图文协同产生更强传播效果 |

## 六、论文层面的实施影响

1. 题目及RQ/H改为“触达规模组—在线目的地内容表征”的比较口径。
2. H1与H2是当前预设的非方向性比较；H3须等待V5—V6质量门；SRM、SAM、视觉和情境异质性分析继续保持`DEFERRED`。
3. `CS-INT`归入V3内容呈现方式的分解分析，不再作为准社会关系或独立受众机制的代理变量。
4. SRM/SAM改称条件共现，纠正其维度为4×10与10×3；IFD上限为10。这些只是论文中的分析说明对齐，编码表未改动。
5. V0现行代码保持不变以维护数据兼容性；只有作者角色试点通过后，才可新增`creator_role`并重新讨论KOL/KOC。
6. 编码表V0表格中的“信任机制”文字属于未被当前字段测量的解释性注释，与本决策不完全一致；本轮依照“先不改编码表”的边界只记录为后续P0修订项，正式改动时须升编码表版本并重审V0相关文件。
