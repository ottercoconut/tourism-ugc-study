# Wave A双阈值选择与Wave B独立评价

> **文档状态**：`HISTORICAL EXPERIMENT DECISION`
> **内部文档版本**：`v1.1`
> **编码表对齐边界**：本文定义旅游相关性清洗模型评价，不定义V0—V11；已按编码表v3.13.0审阅边界，无语义依赖。

## 背景

原最终参考集的验证部分只有110条。既有Qwen与TF-IDF开发结果差异较小，高置信尾部只观察到少量错误，不能仅凭4条与7条UGC误排判断Qwen整体更差。Issue #46 因此建立10,103条独立评价人口和最多600条新人工标签预算。

## 决定

1. Wave A 240条定义为新增外部模型选择验证证据，不物理并入最终700条，不改变442/110/148固定切分；
2. Wave A 同时比较冻结Qwen与TF-IDF，并在标签打开前冻结的网格上自动遍历 `T_keep/T_exclude`；
3. 程序报告保留端误留、排除端UGC误删、人工中间层、自动覆盖、总体概率质量、原始计数和不确定区间；
4. 程序形成Pareto候选并按UGC安全优先规则推荐，研究者确认后封存唯一模型与双阈值；
5. Wave B 最多360条只评价已冻结的模型与双阈值完整策略，按两个模型三段动作的3×3交叉层概率抽样；
6. Wave B 不设置强制非劣门，不允许看结果后换模型或改阈值；证据不足必须如实报告；
7. “100%覆盖”指所有未有人工作答的记录均进入 `auto_keep / manual_review / auto_exclude` 之一，允许人工中间层，不等于100%自动化；
8. 不设置延迟复标任务，不以标注参与人数作为进入 Wave B 的门；人工表继续只要求 `tourism_label`；
9. 原148条锁定测试只在模型、双阈值、测试判读和审计策略全部冻结后单次开启。

## 研究者确认结果

2026-08-24，研究者依据 Wave A 完整双阈值分析确认 Qwen head-tail 模型 `e24fc7a65a5e0e52f383725e21607837`，`T_keep=0.14`、`T_exclude=0.86`。该点在10,103条评分人口中路由4,948条自动保留、2,137条人工处理、3,018条自动排除。用于相同人工量描述性比较的 sparse 策略为 `0.20/0.80`，对应5,028/2,167/2,908条；它不是第二个候选，也不形成机械验收门。

冻结身份为 `configs/cleaning-model-routing-policy.yaml`，策略配置 ID `30a0806c341546c749034a07597b8d9b`。这次确认的效力仅限于生成并独立评价 Wave B；审计、锁定测试判读和正式自动路由仍未冻结，因此不能据此启动全量清洗。

## Wave B 独立评价结果

Wave B 360条全部完成，标签为155条 `related`、205条 `unrelated`、0条 `uncertain`。评价 `fc5c2721c4e15e8addf7c55ab115950e` 显示，在约20%人工量下，Qwen `0.14/0.86` 的保留端设计加权误留为0.10%（原始5/115）、排除端UGC误删为0.35%（2/125）、自动决策准确率99.81%；sparse `0.20/0.80` 分别为10.10%（65/130）、3.28%（30/100）和92.22%。Qwen相对风险差的component-bootstrap敏感性区间在两端均低于0。

该结果状态为 `sufficient_for_descriptive_independent_evaluation`，不自动授权部署。分歧层过采样使未加权计数不能代表总体；component-bootstrap在大层零事件下可能偏窄，原始Clopper–Pearson上界又不处理设计权重。因此本决定保持模型和阈值不变，但把下一门定义为“冻结锁定测试判读与审计策略”，而不是直接运行全量自动清洗。

该下一门现已由《[锁定测试判读与双尾审计冻结](2026-08-24-锁定测试判读与双尾审计冻结.md)》完成；本文件继续保留 Wave A/B 的选择与评价谱系，不承担最终测试和部署审计规则。

## 证据边界

Wave A 用于选择，因此不能证明其所选策略最终有效；Wave B 用于独立评价，因此不能继续调节策略；锁定测试是最后的单次模型与策略证据。若新标签获批进入训练，必须生成新模型身份，且进入训练的标签不再是该新模型的独立评价证据。

## 被替代内容

本决定替代 Issue #46 及相关文档中的以下当前执行规则：Wave A不得选择模型或阈值、14天后复标及一致性门、Wave B只关注自动排除的四层抽样、必须预设绝对风险/非劣/最低覆盖硬门。旧运行计划与历史artifact继续按原哈希保留，只是不再代表后续阈值选择和Wave B策略。
