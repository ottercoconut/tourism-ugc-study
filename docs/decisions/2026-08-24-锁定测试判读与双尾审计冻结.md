# 锁定测试判读与双尾审计冻结

## 背景

Wave B 已对固定 Qwen `T_keep=0.14 / T_exclude=0.86` 完成360条独立评价，并在相近人工量下明显优于 sparse comparator。该评价采用动作分歧层过采样和设计加权，足以支持继续，但不能把加权点估计解释为已经证明的部署风险上限。原700条中的148条锁定测试仍未开启；正式自动决定还需要一个不依赖 Wave B 分层权重的部署审计。

## 决定

1. 唯一锁定测试对象是 Qwen 模型 `e24fc7a65a5e0e52f383725e21607837` 与固定阈值 `0.14/0.86`，不再测试候选模型或扫描阈值；
2. 148条测试成员只允许完整读取和预测一次；运行后不得因结果不理想而换模型、改阈值或重开测试；
3. `auto_keep` 至少需要20条支持且不得出现 `unrelated`，`auto_exclude` 至少需要20条支持且不得出现 `related`；两个方向性错误门均为0事件；
4. 任一尾部支持不足时状态为 `INCONCLUSIVE_MANUAL_ONLY`；任一方向性错误出现时状态为 `FAILED_MANUAL_ONLY`；全部满足时只进入 `PASSED_FOR_PROVISIONAL_ROUTING`，仍不产生正式自动决定；
5. Accuracy、0.5混淆矩阵、log loss、Brier、unrelated PR-AUC和三段动作计数全部报告，但不另作通过门，避免在148条上叠加多重检验；
6. 锁定测试通过后，按已冻结概率生成临时三段路由。人工中间层全部人工判断；两个自动尾部分别执行150条帖子级、尾内简单随机无放回盲审，不设平台名额；
7. `auto_keep` 的不利事件是人工标签 `unrelated` 或 `uncertain`；`auto_exclude` 的不利事件是 `related` 或 `uncertain`。每个尾部最多允许0个不利事件；
8. 每尾150条且0事件时，单侧95% Clopper–Pearson上界为1.977%。这是保守的二项上界，不使用有限总体修正，也不表示真实误差为0；
9. 任一审计事件只暂停对应自动动作，并把该尾部转入人工处理。恢复必须产生新策略 ID，并对失败尾部执行新的独立审计；不得换 seed、删除不利样本、替换任务或靠追加样本稀释失败；
10. 两尾审计都通过前，`deployment_status` 保持 `NOT_AUTHORIZED`，不得生成正式 `auto_keep` 或 `auto_exclude` 决定。
