# 1300条标签重训与前瞻性非零风险验收

## 决策

Issue #49 启动一次有限、收口的模型重训周期。最终700条、Wave A 240条和
Wave B 360条共1,300条确定人工标签全部进入新训练池。旧 Qwen 模型
`e24fc7a65a5e0e52f383725e21607837` 的锁定测试结论继续是
`FAILED_MANUAL_ONLY`；原148条测试已经消费，虽然可进入新训练，但必须标为
`historical_test_consumed`，不得再次作为测试或独立评价证据。

旧协议要求自动尾部零方向性错误，这一门适合当时的保守放行决策，但对存在主观
边界的文本分类过严。新协议只对新训练运行前瞻生效，不事后改判旧模型。新候选
必须同时满足：自动排除端的 `related/uncertain` 不高于2%，自动保留端的
`unrelated/uncertain` 不高于5%。区间必须完整披露，但点估计满足门槛即可进入
候选选择；不再要求观察错误数为零或置信上界低于门槛。

## 固定训练与选择边界

1. 训练快照绑定来源、规范正文哈希、源身份和 finalized leakage component；同组
   不得跨折。Wave A/B 设计权重只用于交叉拟合后的总体评价，绝不进入 `fit`。
2. Qwen3-Embedding-4B 对超过内容预算的文本按连续、无遗漏的2048-token预算块
   编码；记录级向量为全部块算术平均后L2规范化，省略token必须为0。
3. 固定且仅比较 Qwen聚合向量＋LinearSVC、字符TF-IDF＋LinearSVC、两者交叉
   拟合logit的逻辑回归融合。完成后停止模型研发，不追加候选族或标注。
4. 三种候选均生成5折 leakage-group OOF，Sigmoid校准也必须交叉拟合，保证成员
   自身标签不进入自身概率。Wave B成员的OOF概率按原设计权重评价。
5. `T_keep=0.01..0.49`、`T_exclude=0.51..0.99`，步长0.01；每个自动尾部至少
   30条原始确定标签。输出完整风险—人工率Pareto前沿；风险合格者优先选择人工
   率最低，再依次比较UGC误删、无关误留、log loss、实现复杂度与稳定候选ID。
6. 历史 Qwen `0.14/0.86` 的Wave B人工率20.36%仅作参照。降低至少3个百分点
   记为明显改善；未达到也接受风险合格的最佳固定候选，不扩大搜索。

选定后使用全部1,300条拟合唯一最终模型并冻结校准器与双阈值。历史测试不重开，
本周期唯一独立部署放行证据改为冻结策略后的新双尾盲审。

## 前瞻性盲审与降级

模型和阈值冻结后，对尚未人工标注的完整人口执行纯预测，并从 `auto_keep` 与
`auto_exclude` 各简单随机无放回抽150条。任务为UTF-8 BOM四列表；人工只填写
`tourism_label`。排除端最多允许3条 `related/uncertain`，保留端最多允许7条
`unrelated/uncertain`。同时报告单侧Clopper–Pearson和按leakage component聚类
区间，但区间不作硬门。

抽样一次冻结，不得补抽、替换、追加或改阈值稀释失败。某一尾失败只把该动作
降为人工；两尾失败则全部人工；通过尾可以独立启用。1,300条训练成员直接使用
人工标签，300条审计成员也由人工标签覆盖模型动作。自动排除只写派生决定，源库
始终只读。正式推理不得调用 `fit`，并须支持checkpoint、严格复用和批次幂等。
