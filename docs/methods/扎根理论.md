# 扎根理论（Grounded Theory，GT）——从数据里"长出来"的理论

---

## 1）一句话抓住它的魂

> **扎根理论不是先立一个假设再去验证，而是让理论从数据里"自下而上"地长出来。**  
> 你带着问题进入现场，但通过**系统性编码**，把原始材料（访谈/观察/文本）逐步抽象成概念、范畴，最终形成一个能解释现象的过程性理论。

关键词：**不先验假设、持续比较、理论抽样、直到饱和**。

---

## 2）它适合解决什么问题？

最适合回答这种类型的研究问题：

| 适合 ✅ | 不适合 ❌ |
|---|---|
| "**XX人群**在面对**XX情境**时，是如何**经历/应对/决策**的？" | "变量A是否显著正向影响变量B？"（那是量化假设检验的地盘） |
| "这个现象背后的**机制/过程**是什么？" | 你已经有一个成熟理论框架，只想跑回归验证 |
| 现象较新、文献不充分、本土语境强 | 你要做的是描述统计代表性（那要概率抽样+大样本） |

典型选题句式：*"××群体在××情境下的××体验/适应策略/决策机制——基于扎根理论的探索性研究"*

---

## 3）三大流派：你得先站队，论文才站得住

扎根理论名义上是一个方法，实际上**内部有三个主要阵营**，写论文第一件事就是明确你跟谁：

| 流派 | 代表人物 | 核心立场 | 对"文献回顾"的态度 |
|---|---|---|---|
| **经典GT** | Glaser & Strauss (1967) | 强调理论**自然涌现**，研究者尽量悬置预设 | **正式文献综述放在编码后期**，前期只读最少必要背景 |
| **Straussian GT** | Strauss & Corbin (1990) | 更结构化、更"可操作化"，引入**条件—行动—结果**的编码逻辑 | 允许更多前期文献介入，流程更步骤化 |
| **建构主义GT** | Charmaz (2006) | 知识是**共同建构**的，研究者立场、语言、权力都要反思 | 强调反思性，理论不是"被发现"而是"被建构" |

> 📌 **实操建议**：国内硕博论文最常用的是 **Straussian GT**（流程清晰、评审好通过）；如果你做的是偏批判/话语/身份认同议题，**Charmaz 的建构主义立场**更贴合；纯正 Glaserian 反而容易因"太纯粹"被实务型评审质疑脱离问题意识。

## 4）核心流程：从访谈稿到理论的"三阶编码"

### 4.1 总体循环逻辑（这个图要刻在脑子里）

```
初始抽样 → 收集数据 → 开放编码 → 写备忘录
         ↑                              ↓
    理论抽样 ← 发现缺口/新概念 ← 主轴编码/轴向编码
         ↑                              ↓
                            选择性编码 → 核心范畴 → 理论模型 → 达到饱和→停
```

关键原则：**数据收集和分析是交替进行的**（不是一次性收完再分析）。

---

### 4.2 第一阶：开放编码（Open Coding）——"打碎、命名、归类"

目标：把原始语句拆成有意义的片段，赋予概念标签。

**做法：**
1. 逐行/逐段读转录稿
2. 对每一段问：**这里发生了什么？当事人说的是什么现象/动作/感受？**
3. 给现象贴概念标签（code）
4. 相似概念聚成**范畴（category）**

例（假设研究"职场新人如何应对PUA式管理"）：

| 原话片段 | 概念（code） | 范畴 |
|---|---|---|
| "他每次开会当众点我名，我回家反复想是不是我真不行" | 公开贬损、自我怀疑内化 | 心理压迫机制 |
| "我就装听不懂，把活儿拖着，让他自己急" | 消极抵抗、任务拖延 | 隐性对抗策略 |
| "后来找了师兄问，他说这公司都这样，我就开始投简历了" | 外部确认、退出准备 | 退出路径 |

> ⚠️ 开放编码最容易犯的错：**把code写成大词**（"心理压力""管理问题"），等于什么都没说。好code应该**贴着材料、可回溯、有区分度**。

---

### 4.3 第二阶：主轴/轴向编码（Axial Coding）——"把碎片的因果逻辑拼起来"

目标：回答——这些范畴之间**怎么联系**？在什么条件下？通过什么行动/互动？导致什么结果？

Strauss & Corbin 提供一个非常好用的骨架（不是铁律，但是论文的"叙事脚手架"）：

```
[因果条件] → [现象]
    → [情境/干预条件]
        → [行动/互动策略]
            → [结果/后果]
```

回到上面例子可能长出：

- **因果条件**：层级权力不对等 + 绩效考核模糊化
- **现象**：持续贬损性评价
- **情境条件**：新人社会网络强弱、经济缓冲能力
- **行动策略**：①内化自证 ②隐性抵抗 ③外部求助/退出
- **结果**：短期顺从但长期离职倾向 / 或形成"伪装胜任"的生存模式

这步做完，你就有了**过程模型**的雏形。

---

### 4.4 第三阶：选择性编码（Selective Coding）——"找到一根主线把所有东西串起来"

目标：识别**核心范畴（core category）**，让它成为整个故事的主轴，其他范畴围绕它展开。

判断"核心范畴"的标准（给你一个可操作的检查表）：
- ✅ 频繁出现在数据中
- ✅ 能把大多数其他范畴"解释通"
- ✅ 对应你研究问题的实质关切
- ✅ 放进它之后，整个模型变得**简洁且有解释力**

例：核心范畴可能是——**"防御性自我边界的重建"（通过退出/伪装/对抗三种路径）**

## 5）两个你必须写清的"硬门槛"概念

### 5.1 理论抽样（Theoretical Sampling）
> 不是随机抽样，而是：**下一步找谁/去哪儿，由当前分析缺口决定。**

比如编码时发现"有家庭支持的新人似乎更敢怼回去"，下一步就**主动去找**经济独立/有家庭托底 vs 无托底的受访者，去验证/细化这条线索。

### 5.2 饱和（Theoretical Saturation）
> 新数据不再产生**新概念、新属性、新关系**，范畴边界稳定。

论文里不能只写"达到饱和"四个字，要交代：
- 总共多少份有效资料（访谈几人×几次、观察几场）
- 在哪一轮编码后饱和（通常开放编码阶段增长最快，到主轴后期明显放缓）
- 哪一两类新个案的加入"不再带来新范畴"——举个例子说明

## 6）写论文时的标准章节结构（国内评审友好版）

```
第一章 绪论
  1.1 研究背景与问题由来
  1.2 研究问题（开放式，非假设检验式）
  1.3 研究意义

第二章 文献综述（注意GT立场！）
  2.1 相关议题的现有研究
  2.2 现有研究的不足（为GT的必要性背书）
  2.3 本研究的切入点

第三章 研究方法
  3.1 为什么选扎根理论（为什么不能用量化/为什么现象需要探索）
  3.2 流派取向（Straussian / Charmaz /…）
  3.3 研究对象与理论抽样过程
  3.4 数据收集（访谈提纲框架、场域进入、伦理）
  3.5 数据分析流程：开放→主轴→选择性编码
  3.6 信效度/严谨性策略（见下节）

第四章 编码分析与范畴生成（最"实"的一章）
  — 开放编码表示例 → 范畴形成
  — 主轴编码：条件—策略—结果链条
  — 选择性编码：核心范畴与理论模型图

第五章 理论模型阐释（把模型讲成一个"故事"）
  — 各路径的过程机制
  — 反例/边界条件（很重要！）

第六章 讨论与启示
  — 与既有文献对话（这时才充分展开对比）
  — 实践/政策/干预含义
  — 局限与后续研究
```

## 7）GT 的"严谨性"怎么辩护？（评审最爱挑这块）

扎根理论没有 p 值，但你可以用这些标准回应：

| 标准 | 做法 |
|---|---|
| **可信性（Credibility）** | 成员核查（member checking）：把提炼的范畴/故事回给受访者确认 |
| **可追踪性（Auditability）** | 保留编码轨迹：原始语段→code→范畴→模型（附录放编码示例表） |
| **可转移性（Transferability）** | 厚描（thick description）：把场域/语境写足够细，让读者判断能否迁移 |
| **反例处理** | 刻意呈现"不符合主路径"的案例，说明边界条件 |
| **反思性** | 你自己的身份/预设如何影响提问和编码（尤其 Charmaz 取向） |

## 8）最常见翻车清单（避开就能甩开同班同学）

1. **把扎根理论当"主题词频数统计"**——编码不是贴标签池，要有**关系与过程**
2. **开放编码阶段就急着建模型**——顺序不能省
3. **文献回顾写得太满**——变成"套框架"，违背GT精神；但也别走极端完全不引
4. **访谈提纲固定死**——GT要求提纲随编码动态迭代
5. **样本量焦虑**——GT不看 n≥300，看**信息密度与饱和**；但通常 15–30 个深度个案是常见可辩护范围（取决于异质性和问题复杂度）
