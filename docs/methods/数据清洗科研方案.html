1. 研究目标与边界

数据清洗只判断一条候选帖子是否与青岛旅游研究相关，目标是以可复核的人机流程排除无关内容，并控制最终保留语料中的残留无关风险。所有来源帖子属于同一个文本分类任务；模型只读取规范化文本。平台只用于来源谱系、数量和样本构成披露，不作为模型特征、切分层、阈值、审计配额或分类性能比较维度。

规范化必须先从冻结采集快照恢复主体文本，再执行 Unicode、URL、话题、提及、表情和空白规则。Quill Delta JSON 只按原顺序拼接字符串 insert；attributes、图片和截断节点不进入模型。疑似 Delta 但损坏、操作结构非法、含未知嵌入或没有文本时标为结构不可用。该判断依据内容结构而非平台；旧派生库中的污染文本只保留为谱系，训练读取最终 CSV 中经新规则绑定的 normalized_model_text。

自动排除只改变派生分析语料的纳入状态，不删除源数据，不回写正式采集库。KOL/KOC、内容编码和视觉研究中的平台变量与分析设计不属于本清洗方案。

2. 最终700条不重复建模参考集

只有一份恰好700条的最终 CSV 及其唯一配对 finalized manifest 是权威标签证据。现有完成 CSV、旧 manifest、重复候选、人工决定、候补队列和补充标注只作为生成谱系。最终成员必须身份唯一、标签仅为 related 或 unrelated，且不存在两端同时保留的最终确认重复关系。

现有700条规范化文本执行完整 700 × 699 / 2 = 244,650 无序对比较。字符3–5 gram TF-IDF余弦相似度 >= 0.80 只产生人工候选；精确规范哈希相同自动成组，低于阈值但由人工明确识别的重复边允许显式补入。重复判断只依据文本内容，不能读取旅游标签；确认边形成稳定连通分量，组内标签冲突必须另行最终确认。文献把近重复理解为主体内容相同而差异仅在广告、计数、时间戳等非实质部分；网页元数据和附属结构会显著损害检测准确率，因此本研究把“主体可建模内容是否相同”作为人工标准，不把同主题、同地点、相同模板或相似度数值本身当作重复结论（Manku et al., 2007；Gibson et al., 2008）。

初始700条的每个确认重复分量只保留一个建模代表。全部成员优先选择规范化文本更完整者，再按稳定帖子身份决胜；样本框、平台和旅游标签均不参与。被排除成员不从源库或谱系删除。各样本框缺口使用固定种子、读取候补标签前冻结的全局队列补足；平台不进入配额或排序。候补须与初始700条全部谱系成员（包括已排除成员）及同轮候补比较，并沿初始确认分量传播；仅由候补组成的确认重复分量沿用同一代表规则，触及任一已有确认分量成员的候补不得计数，也不重新抽样既有代表。扩展候补前缀后，既有代表与累积候补的标签冲突仍须人工最终确认；非代表的既有标签不得因重复关系自动转移给新代表。

3. 首个正式模型与泄漏控制

首个正式模型采用规范化文本、字符 TF-IDF 与固定 C=1.0、class_weight=balanced 的线性 SVM，不执行隐式超参数搜索。作者关系、精确重复关系和最终确认的近重复关系共同组成泄漏分组；同一分组不得跨训练、验证和测试集合。

全体参考集统一按时间留出 20% 测试候选，再扩展到候选所连接的完整泄漏分组，因此最终测试比例可以略高于 20%。剩余记录进行全局分组分层的训练/验证切分，平台不参与名额分配。训练集内部最多使用五折分组交叉验证；若泄漏分量结构不能支持五折，可下降到仍保证每个拟合端和留出端都有双类的折数，否则失败关闭。每条训练记录只生成一次折外 SVM 分数，再用无正则一维 Sigmoid 拟合校准器，将分数转换为无关概率 p_unrelated。锁定测试集不参与特征、超参数、校准器或阈值选择。

训练运行只报告训练折外和验证集的总体 Precision、Recall、F1、PR-AUC、混淆矩阵、Brier score 与 log loss；其中 0.5 只作验证诊断分界，不是路由阈值。训练阶段将测试集标为 locked_not_opened，不生成测试概率或测试指标。阈值和验收门冻结后才开启一次锁定测试，报告总体阈值表现、自动覆盖率和时间切片。平台只披露来源数量与构成，不报告分类性能或稳定性差异。

3.2 TF-IDF 的提升空间与实验优先级

当前结果说明字符 TF-IDF 对高置信度尾部具有区分力，但对短文本、广告伪装成游记、真实体验中夹带推荐话术，以及新闻/产业/城市资讯与游客 UGC 的身份边界仍不足。误差集合是模型选择的困难样本，不能据此估计全体标签错误率；但其中仍出现与“游客体验或旅游决策为主体、纯广告和非游客身份内容为无关”不一致的标签迹象，故下一轮首先是独立标签一致性复核，而不是直接把全部误差归因于模型。

  1. 标签门：对训练 OOF 与验证中“模型与人工标签强烈矛盾”的记录做隐藏模型答案的一致性复核：编码者只看到文本和标签规则，不看到原人工标签、模型类别、概率或该记录为何入选；同时混入按原标签、数据切分和文本长度匹配的随机预测正确对照。匹配先固定同一长度层，层内不足时仍固定标签和切分、改取字符长度最近者，并单独披露放宽数量。两类样本分开报告，随机对照用于发现复核者是否会把本来正确的标签误改，不能用模型挑出的矛盾集合推断总体标签噪声。
  2. 首轮稀疏 challenger：只比较三类有限候选：现有字符 TF-IDF＋线性 SVM 的预登记小网格、字符 binary count＋NB log-count ratio＋线性 SVM，以及与同一字符 TF-IDF 配对的逻辑回归。NB 比率固定使用 alpha=1、类别内 L1 归一化和 log(P(feature|unrelated)/P(feature|related))，且必须在每个拟合折内估计。标题/正文分通道和中文分词特征不进入首轮，因为现有误差证据尚未显示字段权重或分词是主要瓶颈；固定它们可使比较集中在表示权重与分类损失的增量价值。Wang 与 Manning 在其情感和主题分类任务中报告了 NB-SVM 的增益，但公开任务分数不能直接外推到本研究。
  3. 调参门：只允许预先登记的小网格：字符 n-gram 范围固定比较 2–5、3–5、2–6，min_df 比较1和2，线性模型正则强度比较0.3、1和3；max_df=0.995、sublinear TF、类别权重、规范化文本和随机种子保持冻结。候选选择仅在训练侧嵌套泄漏分组 OOF 中完成。当前验证集已经被查看，只允许唯一训练侧胜出者进行一次次级开发稳健性检查，不能承担最终无偏验收。
  4. 后续语义 baseline：sparse 验证已方向一致，但其改善幅度和固定开发概率带仍提示人工工作量可能较大，因此另行预登记并运行一个独立模型族，而不继续扩 sparse 网格。首次基线固定使用本地 Qwen3-Embedding-4B 冻结编码器、单通道全文、统一中文任务说明、2048 token、2560维 L2 归一化向量和唯一 C=1 逻辑回归概率头；不做 fine-tuning、LoRA 或模型/API切换。其安全错误改善但概率质量验收失败。失败后另行冻结的 Issue #45 三层树依次比较缓存向量分类头、无泄漏 sparse＋Qwen 融合、英文 instruction＋head-tail 双视图；任一层通过既有训练门后停止扩展。Qwen3-Embedding 论文与模型卡支持其中文、分类表示、MRL自定义维度及 instruction 设计，但公开 MTEB/C-MTEB 分数不能外推到本研究。
  5. 评价门：除总体 Accuracy、F1 和 PR-AUC 外，必须报告 Brier、log loss、两类错误、风险—覆盖率曲线及候选阈值下的自动覆盖。三段式路由允许低置信度弃权；选择性预测文献支持单独评价准确率与覆盖率的权衡，但不替本项目决定 T_keep 或 T_exclude。

4. 三段式路由

模型和 Sigmoid 校准器作为不可变模型 artifact 冻结。阈值策略独立保存，并满足 0 ≤ T_keep < T_exclude ≤ 1。路由定义如下：

条件动作
p_unrelated ≤ T_keep自动保留
T_keep < p_unrelated < T_exclude进入人工处理
p_unrelated ≥ T_exclude从派生分析发布中自动排除；源数据不删除

当前阈值状态：T_keep = UNSET，T_exclude = UNSET。在两个阈值、测试门和审计门全部冻结前，系统未来即使能够输出 p_unrelated，所有未有人工作答的记录也只能进入人工处理，不得自动保留或自动排除。

人工结果优先于模型建议。阈值调整只产生新的不可变策略 artifact，不重新训练或替换冻结模型。

5. 冻结模型的全量与增量推理

模型通过验收后，初始未标注人口和未来新增记录都调用同一个冻结模型。新增记录完成结构门与同版文本规范化后直接推理，不调用 fit，也不因增加一个批次而替换模型 artifact。每次推理保存模型 ID、阈值策略 ID、目标批次、规范化输入 manifest、p_unrelated、路由动作和输出 manifest。

人工灰区、未来新增人工结果和保留集审计分别使用独立的完成 CSV 与 manifest。数据库只保存最终帖子决定，以及对应 CSV 哈希、任务身份、模型 ID 和阈值策略 ID 等谱系引用；人工标签本身仍以冻结 CSV 为权威证据。

6. 可靠性证据与失败降级

部署后的常规审计对象是最终保留人口，采用全局抽样，不设置平台配额。保留集审计的事件定义、样本量、最大事件率、单侧置信上限和恢复条件目前均为 UNSET，须在代码框架完成后单独讨论并冻结。

保留集审计失败时，冻结模型仍可继续打分，但自动保留立即暂停；原本会自动保留的记录转入人工处理。自动排除和人工灰区仍按已冻结策略运行。恢复自动保留必须绑定新的阈值策略，并满足尚待冻结的恢复条件，不能修改既有运行结果。

不对自动排除人口实施常规随机审计。因此正式可靠性声明严格限定为“最终保留语料的残留无关风险受控”。避免过度删除的证据仅来自锁定测试集上的总体指标、混淆矩阵和阈值表现；这些证据不能等同于部署期对全部自动排除记录的直接审计，论文必须披露这一限制。

7. 阈值阶段与正式化条件

下列项目现在仍为 UNSET：T_keep、T_exclude、保留集审计事件定义与样本量、最大事件率、单侧置信上限、最终锁定测试指标最低门、自动覆盖率最低门及审计失败后的恢复门。开发 challenger 验收门已冻结，不应与这些生产/最终门混同。阈值选择只能使用训练部分的折外预测或独立验证证据，并遵循预先定义的效用权衡；锁定测试集只用于对已冻结模型和策略作一次最终验收，不得据其结果反复调整阈值。
