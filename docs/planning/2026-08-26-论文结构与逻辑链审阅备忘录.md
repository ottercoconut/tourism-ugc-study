# 论文结构与逻辑链审阅备忘录

> 形成日期：2026-08-26  
> 性质：只读审阅意见，不替代编码表、研究决策或正式分析计划  
> 审阅基线：当前工作树中的论文草稿、研究决策、编码与清洗实现、试点产物及开放获取文献  
> 文件边界：本轮不修改任何既有文档；本文件只记录建议

## 一、总体判断

论文可以成立，但应进一步收缩为一篇**文本优先、描述与比较导向的结构化内容分析论文**。最稳妥的主张不是“KOL/KOC如何影响游客”，而是：

> 在作者证据达到预设质量门后，比较研究内操作化的KOL型与KOC型个人旅游UGC创作者，观察其青岛目的地内容在资源调用、呈现方式和评价性表达上的分布差异；粉丝规模作为独立触达变量处理，结论不越过生产端内容表征。

当前设计真正有价值的部分有三项：

1. 把作者角色与粉丝规模分开，避免“用粉丝定义KOL/KOC，再把规模差异解释为角色差异”的循环逻辑。
2. 把受众目的地形象、受众心理和传播效果排除在当前可检验范围之外，使主张与数据一致。
3. 已经形成只读快照、任务隔离、双人编码、裁决、信度和模型验收的工程契约，可支持透明复现。

当前最大的结构问题不是理论不足，而是**候选分支太多**。正文同时保留RQ1—RQ4、H1—H8、SRM、SAM、视觉轨、跨模态、商业披露、平台异质性和主动学习，容易让读者把一篇可执行的内容分析误读成尚未完成的复杂机制论文。

## 二、建议锁定的唯一主逻辑链

```text
青岛个人旅游UGC创作者总体
        ↓
平台账号 × 固定作者证据窗口
        ↓
作者角色：KOL_TYPE / KOC_TYPE（主比较，须通过质量门）
+ 独立触达规模：reach_tier / log1p(follower_count)
        ↓
固定文本片段上的V3—V6内容表征
        ↓
共同校准 → 新样本独立盲标 → 裁决前信度 → 规则冻结
        ↓
帖子/片段指标先在作者内聚合，再进行作者等权比较
        ↓
报告分布、组间差异及平台/触达规模敏感性
        ↓
仅解释生产端内容表征，不解释受众心理、传播效果或因果机制
```

这条链已经与现有工程结构基本一致。视觉轨、SRM/SAM和内容模型扩展都可以在主链之外等待，不应反过来阻塞文本论文。

## 三、建议采用的简化论文结构

### 第1章 引言

只完成四件事：

1. 说明旅游UGC是目的地相关信息的公开生产材料。
2. 明确“在线目的地内容表征”不等于受众实际形成的目的地形象。
3. 提出作者角色与触达规模需要分开测量的问题。
4. 给出研究问题和贡献。

青岛案例段落应从宣传性资源罗列改为简短的案例选择理由：研究边界明确、五平台材料充足、作者与帖子可关联、自然与人文资源类型兼具。除非案例选择真的依赖游客量或收入，否则不必堆积宏观统计。

建议只保留两个核心研究问题：

> **RQ1：** 青岛旅游UGC中的目的地资源、内容呈现方式和评价性表达呈现何种分布与组合特征？
>
> **RQ2：** 在作者证据充分并完成裁决的KOL型与KOC型之间，上述内容表征轮廓是否存在差异；这种差异在触达规模和平台情境下是否仍可观察？

视觉图文对应可以保留为“质量门通过后的扩展问题”，但不进入当前核心RQ编号。

当前H1—H3均为非方向性“存在差异”命题，理论上并未预言差异方向。若没有明确的方向性依据和唯一总体检验，建议将其改写为RQ2下的预设比较，而不是保留为假设。H4—H8在冻结前不应继续出现在正式假设表中。

### 第2章 文献综述

建议压缩为三节：

1. **目的地形象与生产端内容表征的边界**：说明帖子可以呈现资源和表达属性，但不等于受众状态。
2. **创作者角色与触达规模**：说明粉丝数、专业权威、消费者经验、持续创作和实际影响不是同一构念；明确KOL/KOC是本研究的试点操作类型。
3. **理论导向的结构化内容分析**：说明V3—V6为何足以回答当前问题，以及固定单位、双人盲标和信度门的必要性。

现有“受众机制的保留边界”不必单列为大节。意义迁移、准社会关系、来源可信度、ELM和情绪感染可压缩成一段排除性说明，随后直接进入当前可测量构念。这样能避免文献综述花大量篇幅介绍正文不会检验的理论。

### 第3章 研究方法

建议保留五节：

1. 数据来源、时间边界、五个平台与纳入排除流程。
2. 作者角色证据包、角色派生和独立触达规模。
3. V3—V6测量框架、固定片段与关键派生指标。
4. 共同校准、独立盲标、裁决、信度和缺失状态。
5. 作者等权的描述与组间比较、平台/规模敏感性、多重比较控制。

V3—V6的全部字段和值域不必逐项复制进正文。正文解释构念、单位、父类和质量门；完整79列文本模板、视觉字段、置信度和证据跨度继续由现有编码表及补充材料承担。这样能显著缩短方法章，又不损失可复现性。

神经网络应被写成**条件性扩展工具**：人工金标先形成可独立报告的研究结果；只有锁定测试证明逐标签和下游估计足够可靠时，模型才扩展到全量。模型不是当前论文成立的必要条件，也不应在没有内容编码模型结果时被列为核心创新。

### 第4章 结果

建议只保留：

1. 样本流转、作者证据覆盖、`UNK/NA`和最终组别支持。
2. 裁决前信度与内容字段质量门。
3. RQ1描述性内容轮廓。
4. RQ2 KOL型/KOC型作者等权比较。
5. 触达规模与平台敏感性。

当前4.5—4.9的`DEFERRED`候选节应在正式成稿时退出结果目录。没有解除质量门的分析不应占据结果章节位置；最多在方法末尾或未来研究中用一段说明。

### 第5章 讨论与第6章 结论

讨论依次回答：发现了什么差异、这些差异如何与既有生产端内容研究对话、角色与规模分离带来什么测量贡献、结果受到哪些数据边界限制。实践启示只讨论内容供给和目的地信息监测，不推断哪类创作者“更有效”。

结论只回到两个RQ，不再次展开所有编码维度和候选模型。

## 四、必须先解决的逻辑门

| 优先级 | 逻辑门 | 通过标准与失败处理 |
|---|---|---|
| P0 | 角色测量是否可用 | 完成共同校准后，用50名未讨论作者做独立盲试标；核心字段达到预设信度且两组有足够支持。当前“每组至少10名”只能证明试点可继续，不能证明正式组间推断已有足够精度。 |
| P0 | 角色与平台/规模是否有共同支持 | 同时检查`creator_role × platform`和`creator_role × reach_tier`交叉表。若角色几乎等同于某个平台或规模档，只报告“角色—平台/规模组合差异”，不声称独立角色差异。 |
| P0 | 内容字段是否冻结 | 共同校准中出现系统性边界问题时，修订规则并用新样本重新盲标；讨论后的同一批样本不能充当正式信度。 |
| P1 | 推断单位是否一致 | 角色是作者级，主比较必须作者等权；帖子级模型只作带作者聚类的敏感性分析，不能把多帖作者当成多个独立作者。 |
| P1 | 多指标检验是否收口 | CSP、IMP和评价性字段分别形成预先定义的指标族，先报告总体轮廓和区间，再对同一指标族做FDR控制；不要为每个标签再生一条假设。 |
| P1 | 模型扩展是否改变结论 | 分别报告人工金标结果和模型扩展结果，并比较关键估计量偏移。模型F1较高不自动证明组间差异无偏。 |

## 六、建议重写或降级的主张

1. “方法论创新”宜改为“透明的测量与复现设计”。理论导向编码、双人信度和预训练模型辅助本身并非新方法。
2. “KOL/KOC身份”始终写成“研究内操作类型”或“KOL型/KOC型”，避免暗示存在跨平台通用金标准。
3. “资源调用”“内容呈现方式”和“评价性表达”可以描述与比较；“说服力”“受众形象改变”“传播效果”“真实性”不能由当前数据推出。
4. V3中的“策略”只表示可观察呈现模式；SRM/SAM若未来启用也只是条件共现，不是传导或机制。
5. `ORDINARY`只是未满足试点组合的残余类型，不能改写为“普通游客”第三组。
6. 青岛案例贡献应落在有边界的多平台数据与目的地资源情境，不必声称具有全国或跨文化普适性。

## 八、最小执行顺序

1. 完成当前25名作者与25篇文本的共同校准，集中记录真实边界问题。
2. 只修订被真实分歧证明有问题的规则，冻结下一版角色与文本编码规则。
3. 使用未讨论的50名作者完成角色盲试标；同时用新文本样本完成内容字段盲试标。
4. 先查看角色信度、`UNK`比例、两组支持以及平台/触达规模共同支持，再决定是否保留当前标题和RQ2。
5. 以人工金标先完成描述性结果和作者级主比较；模型扩展通过质量门后再加入。
6. 视觉、SRM/SAM和跨模态不进入这篇论文的最小可发表版本，除非文本主线完成后仍有充分时间和独立证据。

## 九、最终建议

当前最合适的论文不是“大而全的多模态影响机制研究”，而是“一篇测量边界清楚、角色与规模分开、作者级推断透明的旅游UGC结构化内容分析”。只要把八个候选假设收缩为两个研究问题，把视觉与共现矩阵移出核心目录，并让人工证据先于模型扩展，论文的逻辑会更短、更稳，也更贴合仓库已经形成的工程能力。
