# Label Studio工程难度简报

## Material Passport

- **Document Status**：`CURRENT_ALIGNED`
- **Internal Version**：`v1.0`
- **Canonical Artifact**：`docs/data-dictionary/编码表.md`
- **Canonical Version**：`v3.6.1`
- **Execution Maturity**：`CALIBRATION_READY / NOT_FROZEN`
- **文档性质**：工程工作量评估，不授权实施，不改变编码语义

## 一、总体判断

Label Studio Community可以用于本研究，但难点不在软件安装，而在将编码表完整转化为可用界面、规范数据和严格盲标流程。

- 安装与本地部署：**低—中难度**
- 共同校准版界面与数据适配：**中高难度**
- 双人独立盲标、信度与仲裁链：**高难度**
- AI预标注、主动学习与选择性复核：**高难度，后期实施**

建议采用“**Label Studio负责人工录入和证据框选，项目程序负责任务准备、格式转换、校验、信度和仲裁**”的轻量方案，不自建完整标注平台。

## 二、工程同伴需要完成的主要工作

| 工作 | 主要内容 | 难度 |
|---|---|---|
| 本地部署 | 固定Community版本，配置持久化、备份和恢复 | 低—中 |
| 任务导入 | 将固定`seg_id`和不可变`raw_text`转换为Label Studio任务 | 中 |
| 标注界面 | 按V1/V2/V3/V5展示30余项字段、状态值和逐字段置信度 | 高 |
| 条件与校验 | 区分`0/1/UNK/NA/UNRESOLVED`；低置信触发备注；不静默改码 | 高 |
| 文本证据 | 支持中文、emoji、重复引文、多段与重叠证据的offset | 高 |
| 导出适配 | 保存原始JSON并转换为项目规范`labels.csv` | 高 |
| 双人盲标 | 建立A/B隔离实例，保证两人互不可见且结果可按稳定ID合并 | 高 |
| 信度与仲裁 | 在平台外计算逐字段Krippendorff's alpha并保留原始判断 | 中—高 |
| AI协同 | 金标通过后再接入预测、复核队列和主动学习 | 高，延期 |

仓库已有共同校准CSV模板、规范长表、确定性转换器和部分契约测试，可以复用；目前仍需新增Label Studio标签配置、任务导入、JSON适配和A/B隔离流程。

## 三、规划工期

以下为一名熟悉Python和Docker的工程人员的净工程人日，不含人工编码、模型训练和视觉轨：

| 阶段 | 估算 | 启动条件 |
|---|---:|---|
| 10片段技术探针 | 2—4人日 | 现在可做 |
| 共同校准文本MVP | 累计7—13人日 | 技术探针通过 |
| 独立盲试标文本链 | 累计12—22人日 | 文本T0关闭并使用新样本 |
| AI协同生产层 | 另增8—15人日 | 人工信度门通过、测试集锁定 |
| 视觉轨 | 暂不估算 | 视觉T0关闭 |

若工程人员此前不熟悉Label Studio配置和JSON结构，建议增加20%—40%的学习与排错缓冲。

## 四、当前不能由工程人员决定的事项

当前编码表仍为`NOT_FROZEN`。以下内容必须由研究团队先在编码表中裁决：

1. 各字段最终允许的`UNK/NA`范围及专门边界规则；
2. `at_eval_subtype`是单选还是多选，以及多评价共现与信度门；
3. B站、抖音封面、抽帧和普通配图的视觉研究人口；
4. V11/V12视觉标签的唯一裁决规则。

工程人员不得因界面便利性修改字段、值域或观察单位，不得把空白当0，不得允许修改`seg_id`或`raw_text`，不得让模型建议进入共同校准、独立盲标或锁定测试集。

## 五、建议推进顺序

1. 共同校准继续使用现有CSV/Excel流程，不等待Label Studio。
2. 工程同伴先用10个片段验证高维界面、Unicode offset和无损导出。
3. 探针通过后再完成共同校准MVP。
4. 文本T0关闭后，建立A/B隔离盲标版和平台外信度链。
5. 人工信度通过后，才接入AI预测、主动学习和选择性复核。

Label Studio Community缺少本项目所需的细粒度权限、自动重叠分配、内置信度与完整审核流程，因此正式盲标建议使用两个隔离实例，信度和仲裁放在平台外完成。参考：[官方版本对比](https://labelstud.io/guide/label_studio_compare)、[Community用户权限](https://labelstud.io/guide/signup)。

## 六、结论

对两人团队而言，Label Studio Community是可行的录入工具，但不是开箱即用的研究系统。当前最合理的工程承诺是**先完成2—4人日的技术探针**；是否继续投入完整版，应由高维界面、Unicode offset和无损导出三项结果决定。视觉轨与AI协同均不应进入当前首期开发。
