## 一、研究总体与证据边界

1. 研究总体是个人旅游UGC创作者；机构和多人账号只用于范围审计。
2. 研究对象是生产端可观察的在线目的地内容表征，不是受众已形成的目的地形象。
3. KOL型/KOC型由独立作者证据包判断，粉丝量只形成独立的`reach_tier`。
4. 文本V3—V6是主轨，视觉V7—V11在研究人口、编码边界和独立质量门通过后加入。
5. 任何组间差异都必须服从编码员信度、组别支持量和模型效度边界，不解释为受众因果效果。

## 二、原研究问题

> **RQ1：** 青岛旅游UGC中，目的地资源、内容呈现方式、语言功能与表达方向，以及被评价或建议的目的地属性，分别呈现出何种分布与组合特征？
>
> **RQ2：** 在作者证据充分且经双人裁决的KOL型与KOC型之间，上述在线目的地内容表征轮廓是否存在差异？
>
> **RQ3：** 在评价或建议性片段中，KOL型与KOC型对哪些目的地属性作出何种方向的表达；这些差异在触达规模与平台情境下是否仍稳健？
>
> **RQ4（DEFERRED）：** 在视觉轨通过独立质量门后，同一帖子文本V4资源集合与视觉V7资源集合呈现何种对应关系；作者平均后的对应程度在KOL型与KOC型之间是否不同？

## 三、原假设体系

> **H1：** 在作者角色证据充分且裁决完成的样本中，KOL型与KOC型在资源调用轮廓（IMP）上存在差异。
>
> **H2：** 在作者角色证据充分且裁决完成的样本中，KOL型与KOC型在内容呈现方式轮廓（CSP）上存在差异。
>
> **H3（CONDITIONAL）：** 在V5—V6相关规则和质量门通过后，KOL型与KOC型在评价性内容表征轮廓（ATP、ATD、AIP）上存在差异。
>
> **H4（DEFERRED）：** KOL型与KOC型在内容呈现方式—资源条件共现矩阵（SRM）上存在结构性差异。
>
> **H5（DEFERRED）：** KOL型与KOC型在资源—语言功能条件共现矩阵（SAM）上存在结构性差异。
>
> **H6（DEFERRED）：** 同一帖子文本V4资源集合与视觉V7资源集合的对应程度在KOL型与KOC型之间存在差异。
>
> **H7（DEFERRED）：** 明确商业披露状态（V1）下，内容呈现方式—资源条件共现的描述性轮廓不同。
>
> **H8（DEFERRED）：** 不同平台情境与触达规模下的KOL型/KOC型比较结果存在异质性。

H1与H2是主比较命题；H3受V5—V6质量门约束；H4—H8在原子编码、模型验证及相应数据门通过后才能另行启动。所有假设都是非方向性比较命题，不构成创作者对受众的因果机制。

> **历史编号提示：** 上述H3—H5是Git基线`v3.13.0-role-pilot.1`当时的编号，与现行最高标准`docs/data-dictionary/编码表.md` v3.14.0的H3—H5对应关系不同。本处为保存历史原貌而不改写；当前执行必须使用v3.14.0编号。

## 四、原聚合与关联指标

以下指标在人工编码和裁决后计算，不进入编码员的判断界面；其是否进入最终论文，由原子标签信度、模型效度和预分析决定。

| 指标族 | 核心内容 | 研究用途 |
|---|---|---|
| IMP | V4目的地资源大类与亚类出现密度 | 资源调用轮廓 |
| CSP-L1/L2 | V3父类与子项出现率 | 内容呈现方式轮廓 |
| ATP/ATD | V5语言功能与情感方向分布 | 评价性内容轮廓 |
| AIP-L1/L2 | V6属性父类与子类出现率 | 被评价/建议的属性轮廓 |
| ISP | V3-CS-INT互动实现方式 | 互动形式轮廓 |
| CED/CEI/CER | 资源深度与正负双向强度组合 | 资源加权表达方向 |
| SRM | 内容呈现方式—资源条件共现 | 比较策略与资源的关联轮廓 |
| SAM | 资源—语言功能条件共现 | 比较资源与表达功能的关联轮廓 |
| COD/IFD | 同片段共现密度和平均资源深度 | 补充内容组合特征 |
| 图文对应 | 文本V4与视觉V7的资源映射 | 条件性图文协同分析 |

基础帖子级计数、片段比例和是否出现可作为原子标签的直接汇总，但不替代上述原研究设计中保留的轮廓、矩阵和关联指标。

## 五、原AI协同设计

1. 先完成全人工编码、双人信度、人工裁决和金标锁定。
2. 训练、开发和锁定测试按`author_id`和重复簇隔离。
3. 文本模型使用共享中文预训练编码器和V3—V6混合输出头，逐字段预测人工标签。
4. 主动学习、稀有标签定向选样、数据增强、概率校准和选择性复核均保留为原研究设计中的候选实验。
5. 模型效度包括逐标签Precision、Recall、F1、PR-AUC，macro/micro汇总，并可检查概率校准、子群表现和关键下游估计的人工金标—模型差值。
6. 人工金标锁定后，程序只扩展非金标样本，不回写或修改人工金标。

## 六、原分析设计的保留状态

- H1—H2只在V0角色门、对应文本标签信度门和组别样本门通过后检验。
- H3须等V5—V6规则与质量门通过。
- H4—H8及SRM/SAM/图文指标保持`DEFERRED`，而非删除。
- 平台、触达规模、同一作者多帖和多重比较的最终处理，应在正式抽样框和逐标签支持量可见后写入预分析计划。
- 编码方法改进可提高测量可执行性，但不自动改变本副本中的研究问题、假设或分析结构。
