## 一、以后如何记录

1. **新增备忘、问题、讨论结论和待办都写在本文件。** 同一问题继续更新原条目；新问题使用下一个`B`编号，关闭后不复用编号。不再另建按日期、主题或会话分散的备忘录、问题清单或待办副本。
2. 每项只维护“问题与现状、下一步、完成依据、来源”；有新决定时补日期和结论。没有完成证据时保留“待核验”，不能因为已经有方案、任务包或代码就标为完成。
3. 状态使用：**待解决、待核验、条件启动、暂停、已关闭**。“暂停”不等于问题已解决；“条件启动”不计入本轮必做任务。
4. 本文件管理事项，不取代[编码表](../data-dictionary/编码表.md)的最高标准，也不取代冻结manifest、原始答案、运行记录或正式决策的证据作用。获准的实质改动仍须同步相应规范；清洗科研／工程契约的联动要求继续适用。
5. 已合并的两份旧专题备忘录及旧问题清单已按用户要求删除工作区副本，来源名称、事项映射和可恢复的Git版本记在第六节，不另存备忘副本。正式协议、方法文档、研究决策和运行记录仍按原目录维护，其遗留问题、后续事项及关闭进度统一在此登记。
6. 编码员继续在数字平台记录原始疑问；负责人将需要研究讨论的问题汇总到对应条目。本文只放去敏摘要和内部证据位置，不复制原始UGC、真实账号、图片、令牌或受限全文。

7. **显示顺序按状态排列：待解决 → 待核验 → 条件启动 → 暂停 → 已关闭。** 总览与详细记录保持同序，同一状态内按原编号排列；编号永久保留，不随位置变化重编号。状态排序用于查阅，不替代各项依赖与第七节执行顺序。暂停及历史事项保留在第五节，后续关闭的编号事项移至详细记录末尾并保留关闭依据。

新增条目格式：

```text
### B16｜问题名称
- 状态／所处阶段：待解决；说明阻塞哪一步。
- 问题与现状：区分已知事实、历史记录与尚待核验的判断。
- 下一步：写清具体动作及必要依赖。
- 完成依据：需要什么决定、文件或验证结果才能关闭。
- 来源／更新：原文位置；日期与本次结论。
```

**2026年9月22日职责梳理：** 以下按[现有编码表第三节](../data-dictionary/编码表.md)解释V3—V6的测量职责，不新增构念，也不代表主问题或分析方案已经冻结。

| 维度 | 负责回答的问题 | 在研究中的用途与边界 |
|---|---|---|
| V3 内容策略 | 内容以什么方式呈现？ | 描述信息提供、知识阐释、情感渲染、互动激发等可观察的呈现方式；不直接证明创作者意图或受众受到的影响。 |
| V4 目的地资源 | 内容呈现了什么旅游资源？ | 描述文本中的资源构成，并为考察同类资源的呈现差异提供条件；不代表目的地真实资源禀赋或质量。 |
| V5 语言功能与情感 | 片段是在陈述、评价还是建议？评价／建议表达什么方向和强度？ | 区分语言功能并记录表达中的评价倾向；不等于受众感受，也不直接测量创作者内在心理。无法判定与不适用不能当作中性。 |
| V6 目的地属性指向 | 评价／建议针对什么属性？ | 区分价格、服务、拥挤、可达性等评价对象；方向与强度须配合同一评价原子片段的V5。没有明确属性评价／建议时不适用。 |

- **易混边界：** V3的呈现方式与V5的语言功能可以共现，不能互相替代；V4区分资源对象，V6区分被评价的属性。例如，孤立的“酒店每晚300元”陈述价格事实，不能仅凭价格出现就标为V6价格评价；“这家酒店太贵”才明确包含对价格的负面评价。该例仅说明边界，不是完整编码金标。
- **与B13的分工：** 本项先明确字段测量什么、可能回答什么问题；B13再确定这些标签如何汇总为指标，包括片段／帖文／作者单位、分母、权重及NA处理。分析设计可以现在开始讨论，无须先运行统计或等待全部数据完成；正式结果计算仍须满足相应数据与测量质量条件。
- **尚未决定：** “负面价格评价占比”可以指价格评价片段中的负面比例，也可以指帖文中出现负面价格评价的比例，两者回答不同问题，不能混用。最终采用哪种输出须结合B01确定，并在B13冻结。当前未执行聚合分析，B02仍待研究问题、字段用途及视觉字段等对应关系完成后关闭。

**2026年9月22日手册落实与剩余边界：** 按用户要求，将V4资源对象／V6评价属性的对照、适用条件与教学判例写入[人工编码员操作指南](../protocols/人工编码员操作指南.md#v4-v6-boundary)，并在编码簿V6处补充入口。此次解释已有规则，不修改规范字段或宣称平台已同步。V3／V5已有概念与明确案例上的区分依据：V3细分实用信息、知识解释、感官／氛围呈现和互动方式，V5区分事实、评价、建议及情感方向；二者可共现，不能互相推导。尚不能据此认定实际编码已能稳定区分，尤其是`CS-INF`与`AT-INF`、`CS-EMO`与`AT-EVL`、操作指导与`AT-SUG`的交界。真实边界核验归B07，独立信度归B08，不需要先做正式聚合分析。
