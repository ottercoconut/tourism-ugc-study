## 一、结论

以项目`papers/`与`literature/papers/`中的相近社科研究为参照，目前设计的主要问题不是理论主线错误，而是**论文外围设计比研究问题本身复杂**。现阶段不需要修改标签编码结构，也不应在尚未获得共同校准数据前贸然删改标签。

本轮建议只做四类简化：

1. 将主论文收缩到三个核心研究问题，视觉问题保持条件启动；
2. 删除或暂缓没有独立理论贡献的自定义聚合指标与非方向性假设；
3. 简化校准结果的报告指标和日程管理，不再为每个环节设置多重重复门槛；
4. 将模型部分降为“人工金标后的扩展工具”，不把复杂模型评价写成主论文贡献。

现行V0—V11全部标签、父子关系、人工填写要求和字段值域维持`v3.14.0`不变。本文件只决定**哪些结果进入主论文、哪些流程可以简写、哪些内容暂不启动**，不决定标签删除、合并或改名。

## 二、文献精度基准

| 文献 | 实际方法粒度 | 对本研究的启示 |
|---|---|---|
| Garay（2019） | 约1500条推文；人工判断属性有无；主要报告频数、比例和季节差异 | 宽标签的出现频率与常规组间比较已经能够支撑旅游内容分析论文 |
| Dorta-Preen与Santana-Talavera（2025） | 52篇Instagram帖子、每帖第一张图、约10个视觉维度 | 图片轨不需要同时承担复杂状态识别和机制解释才能形成辅助结论 |
| Mayring（2000） | 类目围绕研究问题建立，经反馈循环修订，最后可归并到主类目 | 校准的重点是定义能否稳定执行，而不是规则越多越好 |
| O’Connor与Joffe（2020） | 指出代码越多，编码员认知负担和低频代码信度问题越严重；复杂体系可分代码族处理 | 当前编码可分模块执行和报告，不必把全部标签同时提升为主论文变量 |
| Xiao等（2022） | 使用CNN、图像美学模型和综合加权分析大规模旅游图片 | 适合作为后续计算扩展，不应反向抬高当前人工内容分析的必要复杂度 |
| Mehra（2023） | 将文本切到句、短语或从句，对预定义方面做情感分析 | 支持当前片段级方面与情感路径，但不要求同时构造大量自定义指数 |

这些文献的共同精度底线是：研究问题明确、观察单位一致、类目有操作定义、存在编码员训练或信度说明、结果与数据层级一致。它们并不要求每个可计算的字段都进入假设，也不要求所有技术指标同时报告。

## 三、目前真正需要简化的部分

### 3.1 研究问题与假设

现稿同时设置RQ1—RQ4和H1—H8，其中H4—H8已经标记为`DEFERRED`，H1—H3又是“存在差异”的非方向性命题。对探索性结构化内容分析而言，这造成了重复：研究问题已经能够容纳描述和比较，非方向性假设没有增加明确的理论预测。

建议主论文只保留：

> **RQ1：** 青岛旅游UGC中的目的地资源、内容策略、语言功能、情感方向和评价属性呈现何种分布特征？
>
> **RQ2：** 证据充分的KOL型与KOC型创作者在上述内容表征上是否存在差异？
>
> **RQ3：** 上述差异在不同触达规模和平台中是否保持相近方向？
>
> **RQ4（条件启动）：** 当视觉轨通过独立质量门后，帖子文字与图片在目的地资源呈现上具有怎样的对应关系？

H1—H8从主论文当前执行计划中移除。若后续文献能够支持具体方向，再在正式分析前单独提出少量方向性假设；否则使用RQ回答更符合当前探索性证据基础。

这一调整不改变任何V0—V11标签。

### 3.2 聚合指标

现稿列出了IMP、CSP、ATP、ATD、AIP、ISP、CED、CEI、CER、SRM、SAM、COD、IFD等多套指标。它们大多是同一批原子标签的不同组合，容易使论文从“比较内容表征”滑向“解释自定义指标”，并增加读者理解成本。

建议主分析只使用三种帖子级结果：

1. **出现次数**：同一标签在不同片段中出现几次；
2. **出现比例**：出现次数除以帖子有效片段数，用于控制长帖天然拥有更多标签机会；
3. **是否出现**：一个帖子中至少出现一次记1，否则记0，用作简单敏感性结果。

例如一个帖子有3个片段，其中2段出现“氛围体验”，帖子计数为2，帖子比例为`2/3`，帖子出现值为1。两名编码员先完成片段级编码和裁决，再对裁决后金标求和；不在编码过程中计算。

作者层只需先计算每篇帖子的标签比例，再对同一作者取平均，使发帖多的作者不会仅因帖子多而获得更大权重。

主论文暂不使用SRM、SAM、COD、IFD、CED、CEI和CER。原有公式可以作为历史设计保留，但不作为当前编码、校准或模型训练的前置门。该决定不删除其底层标签。

### 3.3 统计方法

建议采用与同领域论文相称的常规分析：

- 标签频数、帖子比例和组别分布；
- 分类变量使用列联表、卡方或Fisher检验；
- 帖子/作者比例使用Mann–Whitney U检验或简单回归；
- 报告效应量与95%置信区间；
- 平台和触达规模作为分层或简单控制；
- 同一指标族存在较多比较时作一次FDR校正；
- 同一作者多帖时优先使用作者平均，只有在确有必要时才使用多层模型或聚类稳健标准误。

不再预先要求复杂多层模型、多个自定义矩阵和多套稳健性检验全部同时完成。若样本量不足以支持控制变量，只做描述性分析并明确限制。

### 3.4 模型部分

人工阶段继续遵守现行边界：所有金标由人完成，编码员不查看模型建议，裁决后锁定金标。金标锁定后，程序才进行格式转换、训练和非金标大样本预测。

主论文的模型评价保留：

- 每标签Precision、Recall、F1；
- macro-F1与micro-F1；
- 按作者和重复簇隔离的锁定测试集；
- 人工金标结果与模型扩展结果分开报告。

概率校准、主动学习、数据增强、复杂层级损失、所有平台子群性能和下游估计偏差审计改为可选扩展。它们可以在模型表现或投稿要求确有需要时再做，不作为人工试编码的阻塞条件。

## 四、标签结构不变时如何降低编码负担

本节只调整组织方式，不改变标签或填写规则。

1. 按V3、V4、V5、V6分四个连续代码族完成，不在同一屏同时铺开全部字段；
2. 每处理完一个片段就完成一个代码族，避免在帖子内反复来回跳转；
3. 标签速查页只显示当前代码族的中文标签、定义、正例和关键排除例；
4. 共同校准中优先讨论会改变主研究结果的父类和常见标签，低频细标签单独列为探索性；
5. 信度结果按代码族汇总呈现，同时保留字段级附表，不在正文逐项解释全部系数；
6. 旧任务包继续使用，除非发现字段、值域或说明与`v3.14.0`不一致。

如果后续真实校准数据显示某些父子字段长期重复、低频或无法稳定区分，再提出单独的标签结构修订；在取得这些证据前不改结构。

## 五、三周校准流程的简化

创作者身份保持独立证据包和独立工作表，文本与图片也相互遮蔽；三条轨道只是在同一周期并行推进，不合并成同一编码任务。

### 第一周：共同校准与问题收敛

- V0沿用25名作者共同校准包；
- 文本沿用25篇帖子共同校准包；
- 图片完成视觉人口与抽样规则后开始共同校准；
- 每个代码族完成“双人独立编码—锁定—讨论—记录决定”；
- 周末冻结盲试标使用的规则快照。

### 第二周：新样本盲试标

- V0使用50名未讨论作者；
- 文本保留已经准备的80篇未讨论帖子作为信度样本。由于当前标签结构保持不变，80篇比50篇更有利于累积部分细标签的阳性例；但它仍只回答“冻结规则在新样本上能否被两名编码员稳定执行”，不代表对海量UGC总体的覆盖；
- 图片样本量在视觉人口确定后按常见类别与边界案例分层，不以覆盖海量图片总体为目标；
- 双方首轮完成前不讨论答案，不修改规则。

### 第三周：信度、裁决与阶段判定

- 先锁定两份原始记录，再计算信度；
- 对分歧进行人工裁决，裁决不覆盖原始编码；
- 每条轨道形成“通过、探索使用、支持不足或需重验证”的结论；
- 只对需要进入主论文的标签作优先判定，完整字段结果放入附录或审计文件。

日程不再规定每天必须完成多少单位、任务顺序轮换、每周裁决时长上限或大量行政状态码。只保留独立编码、规则冻结、裁决前信度和原始记录不可覆盖四条硬规则。

## 六、信度报告的简化

现有标签结构下，字段级信度仍应计算，但报告不必同时堆叠多种统计量。

主指标使用名义尺度Krippendorff's alpha；每个标签同时给出阳性数和原始一致率，足以判断高alpha是否只是由大量阴性造成。解释原则为：

- `alpha >= 0.80`：可进入主分析；
- `0.67 <= alpha < 0.80`：探索性使用并说明限制；
- `alpha < 0.67`：不进入主分析，先复查定义或合并的必要性；
- 阳性过少：报告“支持不足”，不把结果解释为可靠或不可靠。

Cohen's kappa、MASI、bootstrap区间、阳性/阴性一致率和混淆矩阵不再全部列为统一强制项。只有角色多分类、严重类别不平衡或审稿人明确要求时再补充相应指标。

## 七、哪些部分仍然阻塞

在不修改标签结构的前提下，目前真正的阻塞性问题是：

1. **创作者证据可得性**：数据库能否为足够作者提供主页、时间跨度和历史内容；这是V0正式组间比较的数据门。
2. **视觉研究人口**：视频封面是否纳入、抽帧是否排除、多图帖如何取图；这是图片轨抽样前置门。
3. **图文映射标准**：V4资源与V7视觉主体如何映射、无可映射对象如何处理；这是RQ4前置门。
4. **正式人工样本规模**：25/50或25/80只回答规则稳定性，不回答总体覆盖，也不自动等于足够的模型训练集。
5. **推断单位**：正式样本中同一作者多帖的比例和每组有效作者数尚需在统计前确认。

文本V1—V6已经可以按`v3.14.0`进行共同试编码；它不需要等待图文标准或聚合公式。V0也可以独立试编码；其阻塞只影响最终KOL/KOC组间比较，不阻塞文本标签本身。视觉轨仍受第2、3项限制。
