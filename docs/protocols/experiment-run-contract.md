# 正式实验运行契约

> **文档状态**：`CURRENT MULTI-DOMAIN CONTRACT`
> **内部文档版本**：`v1.2`
> **编码表对齐边界**：内容编码与角色实验须记录编码表v3.16.0；清洗实验使用独立标签与事实源。本契约不自行定义任何标签。

一次实验只有同时满足下列条件才可被论文引用：

1. 读取冻结的数据与切分 manifest；
2. 保存解析后的完整配置和随机种子；
3. 保存 Git SHA、Python 和关键依赖版本；
4. 输出机器可读 `metrics.json` 和人可读 `summary.md`；
5. 检查作者、精确重复和已确认近重复泄漏。数据清洗相关性模型只报告总体指标，平台只作来源数量与样本构成披露；内容编码、KOL/KOC 或视觉研究按各自预注册方案处理平台变量；
6. 数据清洗训练必须记录权威完成 CSV 与 manifest 哈希、模型与校准器 ID、全局时间测试成员及折外校准证据；推理必须记录冻结模型 ID、阈值策略 ID、目标批次、逐条 `p_unrelated`、路由动作和输出 manifest；
7. 数据清洗阈值或审计门为 `UNSET` 时，只允许研究性概率输出和人工处理，不得产生自动保留或自动排除；未来新增批次的推理不得调用 `fit`；
8. 数据清洗自动排除只改变派生分析发布，不删除源数据；保留集审计失败时必须暂停自动保留，并通过新阈值策略才能恢复；
9. 不覆盖已有 `run_id`；
10. 论文使用的运行必须保留完整的 `results/<run_id>/` 运行包和 manifest。

Notebook 中临时运行、缺少数据哈希或无法确认切分的结果，只能用于探索，不能作为论文最终结果。
