## 研究问题与边界

本阶段回答：在不改变任何模型的前提下，当前冻结 sparse 与 Qwen head-tail 模型对新的、未进入最终700条参考证据的帖子表现如何？新标签首先且仅用于评价现有两个模型。评价包封存前禁止 `fit`、重校准、调参、候选扩展、模型选择、生产阈值冻结和自动清洗决定。评价结束后，是否把新标签转入未来训练由研究者另行决定；若获批，必须生成新模型身份，这些标签不能再充当重训模型的独立验证证据。

固定评价对象为：

- sparse run `ce19406cd132e55b2eb00531f5cc4cd3`，模型 `1b68baa8bef99d6b9d75b7bf3226cfb4`；
- Qwen head-tail run `bdf73219d584edfcbeea02772716a90a`，模型 `e24fc7a65a5e0e52f383725e21607837`。Qwen 仅为研究 comparator；其既有开发状态仍是 `failed_retain_baseline / validation_not_allowed`，进入本研究不表示部署批准。

计划文件为 `configs/cleaning-model-reliability-study.yaml`，计划 ID `f8e322ea0c53eb2fedbb9509ba200450`，完整 SHA-256 `f8e322ea0c53eb2fedbb9509ba2004502d68107e44a98ffe88618cde8f3b964b`。

## 评价人口

候选构建 `f58a671d0160ba418b3a1589831fa0d6` 含13,858条可用帖子、8,087个 finalized leakage components。最终700条实际触及587个分量；排除这些分量的全部3,755条成员后，评价人口固定为10,103条、7,500个分量。该计数由最终 CSV、只读派生库、冻结源快照文本投影和 leakage build `6048c9aba31e020cb2fae9afb0b676e2` 运行时复核，取代较早交接摘要中的10,112/7,514。

两个模型对同一10,103条各执行一次纯预测。平台不进入文本、分层、抽样、权重、性能门或阈值；锁定测试保持 `locked_not_opened`。

## Wave A：240条探索性成对评价

每条帖子按两个冻结概率进入一个且仅一个分层：两者均不低于0.90、仅Qwen不低于0.90、仅sparse不低于0.90、0.50诊断动作不同、两者均不低于0.50的剩余项、两者均低于0.50。预分配依次为35、45、45、45、35、35。某层不足时先全取，再按其他层剩余容量比例确定性补足。层内使用固定哈希随机键无放回抽样；每条记录保存 `π_h=n_h/N_h` 和 `1/π_h`，因此不是只挑模型错误或不确定项的方便样本。

公开盲标表与既有 `tourism-relevance-completed.csv` 的人工体验对齐，使用 UTF-8 BOM，并按 `task_id / sample_run_id / normalized_model_text / tourism_label` 固定列序保存一条逻辑记录。`sample_run_id` 等于本轮内容寻址 `wave_id`，全表一致；人工只能填写 `tourism_label`，合法值为 `related`、`unrelated`、`uncertain`，不填写原因码或文字说明。`uncertain` 单独报告，不强制转成二元标签。

`source_post_id`、`source_version`、`platform_key`、模型名称、模型概率、抽样分层、入选原因、纳入概率和分析权重全部保存在 Git 忽略的 `private-map.json`，不得出现在人工表。`platform_key` 只作私有来源谱系，不进入模型、分层、抽样或评价权重。

初标完成后同时报告：

- 两模型设计加权 Accuracy、UGC误排率、反向错误率、log loss、Brier 与 unrelated PR-AUC；
- 固定0.90、0.95、0.975、0.99概率网格下的覆盖率与自动排除中的UGC风险；
- 在完整10,103条上冻结25%、40%、50%、60%覆盖率切点后，对人工样本评价对应风险；
- 同一帖子的成对风险差、原始罕见事件一侧 Clopper–Pearson 描述上界，以及 leakage-component cluster bootstrap 敏感性区间。

Wave A 固定为探索性：状态只能到 `WAVE_A_EXPLORATORY_COMPLETE`，不能据此直接选择模型、冻结生产阈值或启动训练。

## 单一标注者稳定性门

由于当前只有一名标注者，本研究不声称双人 inter-rater reliability。初标后至少间隔14天，对全部候选自动排除中的UGC错误、全部 `uncertain` 及其余项目25%固定随机对照进行隐藏首轮答案的复标；不一致项再作最终仲裁。进入确认阶段前要求复标完成率100%、原始一致率至少90%、逐标签一致率至少80%。κ只能描述同一标注者的时间稳定性，不能写成双人一致性。

## Wave B：最多360条确认性评价

只有 Wave A 与复标稳定性证据封存后，研究者才冻结：候选模型、候选阈值、等覆盖 comparator 阈值、可接受的绝对 UGC 误排上限、安全非劣界值和最低覆盖率。缺少任一值，状态保持 `awaiting_researcher_policy`，不能生成 Wave B。

Wave B 从未进入最终700条或 Wave A 的 leakage components 中抽取最多360条，按两模型冻结动作形成 `both_exclude / selected_only / comparator_only / neither` 四层，预分配180/100/60/20。确认门只评价预冻结的绝对风险和等覆盖非劣；不得看结果后换模型、改阈值或放宽风险上限。预算不足时可输出 `inconclusive_budget_limited`，不能把“不显著”改写成安全。
