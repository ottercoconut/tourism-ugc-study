## 研究问题与边界

本阶段回答两个连续问题：第一，新增外部验证证据能否区分当前冻结 sparse 与 Qwen head-tail 模型，并支持选择三段式路由的双阈值；第二，在模型和双阈值不再变化后，独立新标签如何评价完整清洗策略的保留端风险、排除端风险和人工工作量。

固定比较对象为：

- sparse run `ce19406cd132e55b2eb00531f5cc4cd3`，模型 `1b68baa8bef99d6b9d75b7bf3226cfb4`；
- Qwen head-tail run `bdf73219d584edfcbeea02772716a90a`，模型 `e24fc7a65a5e0e52f383725e21607837`。

Qwen 的既有开发状态仍是 `failed_retain_baseline / validation_not_allowed`；进入本研究只表示获得新的成对外部评价，不追溯改写原验收结论。Wave A/B 评价包封存前禁止 `fit`、重校准、候选扩展和读取锁定测试。若未来批准新标签进入训练，必须生成新模型身份，且这些标签不能再用于声称该新模型获得独立验证。

当前人口评分与 Wave A 抽样仍绑定 `configs/cleaning-model-reliability-study.yaml`：计划 ID `f8e322ea0c53eb2fedbb9509ba200450`，完整 SHA-256 `f8e322ea0c53eb2fedbb9509ba2004502d68107e44a98ffe88618cde8f3b964b`。该文件是已启动运行的不可变谱系输入；新的双阈值选择和 Wave B 策略必须以独立配置绑定其产物，不能原地改写该运行身份。

## Wave A：240条模型选择验证

### 抽样与人工表

Wave A 是新增外部模型选择验证集，用来补充原110条验证证据对微小模型差异辨别能力不足的问题。它不物理并入原700条，也不改变442/110/148固定切分。

人口评分计划按两个冻结概率形成六个互斥层：两者均不低于0.90、仅Qwen不低于0.90、仅sparse不低于0.90、0.50诊断动作不同、两者均不低于0.50的剩余项、两者均低于0.50。预分配为35、45、45、45、35、35。层内固定哈希随机键无放回抽样，保存每条纳入概率和倒数分析权重。该抽样既覆盖高置信尾部和模型分歧，也保留对完整10,103条人口作设计加权估计的谱系。

公开人工表固定命名为 `wave-a-tourism-relevance-annotation.csv`，平铺在 Wave A artifact 根目录；哈希子目录保留同字节不可变原件。表格使用 UTF-8 BOM，固定列序为 `task_id / sample_run_id / normalized_model_text / tourism_label`。`sample_run_id` 等于内容寻址 `wave_id`；人工只填写 `tourism_label`，合法值为 `related`、`unrelated`、`uncertain`，不要求原因码或文字说明。

源身份、版本、平台、模型身份与概率、抽样层、入选原因、纳入概率和分析权重只保存在私有映射。平台只作来源谱系，不参与任何计算。`uncertain` 单列报告，不强制转成二元标签，也不计作明确人工决定。

### 双阈值自动扫描

冻结模型输出 `p_unrelated`。每组策略满足：

```text
p_unrelated <= T_keep              -> auto_keep
T_keep < p_unrelated < T_exclude   -> manual_review
p_unrelated >= T_exclude           -> auto_exclude
```

Wave A 标签打开前必须在独立策略配置中冻结双阈值网格。当前拟采用：

- `T_keep` 从0.05到0.20，步长0.01；
- `T_exclude` 从0.80到0.95，步长0.01；
- 两者笛卡尔积共256组；
- 另报告相同自动覆盖率、相同人工率和预登记固定覆盖率下的模型比较。

上述精确网格在配置封存前仍是拟定值，不得写入当前正在运行的人口评分计划。配置冻结后，评价程序不得根据标签增删网格。

每个模型、每组双阈值至少报告：

- `auto_keep / manual_review / auto_exclude` 的完整人口数量与比例；
- 保留端无关内容误留的原始分子/分母、设计加权比例与区间；
- 排除端真实UGC误删的原始分子/分母、设计加权比例与区间；
- 两个自动区间合计的自动决策准确率；
- 设计加权总体 Accuracy、两类错误、log loss、Brier 与 unrelated PR-AUC；
- 同一成员上的模型差值、leakage-component cluster bootstrap 敏感性区间；
- 分层权重有效样本量，以及极端阈值证据不足标记。

人工中间层属于弃权，不得伪装成预测正确或错误。“100%覆盖”只表示每条记录均有三段式去向；自动覆盖率等于保留与排除两个自动区间之和。

### 自动推荐与研究者冻结

程序先删除同时具有更高两端风险且人工量不低的被支配组合，再形成风险—工作量 Pareto 前沿。候选排序依次考虑：UGC误删风险、自动处理量、保留端误留风险、统计不确定性、模型计算与维护成本。程序只生成可复核推荐；研究者确认唯一模型、`T_keep` 和 `T_exclude` 后，另行封存不可变策略 manifest。

Wave A 状态依次为：

```text
WAVE_A_LABELING_COMPLETE
WAVE_A_SELECTION_READY
ROUTING_POLICY_FROZEN
```

Wave A 可以选择模型和阈值，因此不能同时证明所选策略最终有效。不得把 Wave A 的最优点描述成无偏的最终性能。

## Wave B：最多360条独立策略评价

只有 `ROUTING_POLICY_FROZEN` 后才能生成 Wave B。策略 manifest 必须绑定 Wave A、人口评分、唯一模型、`T_keep`、`T_exclude`、候选排序规则和代码身份。研究者已确认 Qwen、`T_keep=0.14`、`T_exclude=0.86`；仅作等人工量描述性比较的 sparse comparator 使用 `0.20/0.80`。这一冻结只授权 Wave B 独立评价，不授权部署或正式自动决定。

Wave B 排除最终700条触及的全部分量，并进一步排除 Wave A 240条触及的227个分量；后者从10,103条人口中整体排除693条，留下9,410条、7,273个分量的新评价人口。

Wave B 按选定模型与 comparator 的三段动作形成3×3交叉层：

| selected \ comparator | `auto_keep` | `manual_review` | `auto_exclude` |
|---|---:|---:|---:|
| `auto_keep` | 一层 | 一层 | 一层 |
| `manual_review` | 一层 | 一层 | 一层 |
| `auto_exclude` | 一层 | 一层 | 一层 |

抽样优先覆盖两模型动作相反、仅一方自动排除、仅一方自动保留、共同排除、共同保留与共同中间区。具体分配必须在读取 Wave B 标签前根据封存人口层大小确定，并保存纳入概率与分析权重；不得固定抽取不存在或容量不足的层，也不得按平台补配额。

冻结容量与分配如下；行是Qwen动作，列是sparse comparator动作，单元格为“人口/样本”：

| selected \ comparator | `auto_keep` | `manual_review` | `auto_exclude` |
|---|---:|---:|---:|
| `auto_keep` | 3,957 / 40 | 856 / 50 | 25 / 25 |
| `manual_review` | 800 / 45 | 834 / 30 | 282 / 45 |
| `auto_exclude` | 122 / 45 | 323 / 50 | 2,211 / 30 |

总样本为360条；最小的25条分歧层全取。层内按固定种子无放回简单随机抽样，每条保存 `n_h/N_h` 纳入概率及其倒数权重。哈希子目录中的不可变原件命名为 `wave-b-tourism-relevance-annotation.csv`；人工工作副本沿用四列 UTF-8 BOM 契约，并以 `wave-b-tourism-relevance-completed.csv` 平铺在 Wave B artifact 根目录。生成器不得覆盖已存在的工作副本。

Wave B 对冻结策略报告与 Wave A 相同的两端风险、自动覆盖、人工量、原始计数、设计加权估计和不确定区间，并提供TF-IDF与Qwen在相同工作量下的描述性比较。它不设置预先决定研究者风险偏好的机械非劣门，也不在看到结果后换模型、改阈值或重排候选。完成状态为 `WAVE_B_EVALUATION_COMPLETE`；是否进入锁定测试和正式推理由研究者根据完整证据另行决定。

若 Wave B 有效样本量过低或关键动作层没有足够支持，报告必须明确 `evidence_insufficient`，不能把没有观察到错误解释为安全。

## 锁定测试与后续训练

原700条中的148条锁定测试不参与模型选择、双阈值扫描或 Wave B 规则调整。只有模型、双阈值、最终测试判读规则和审计策略全部冻结后，才允许单次开启。

若 Wave A/B 评价封存后批准部分新标签进入训练，必须开启新的训练周期。任何进入 `fit` 的 Wave A/B 标签都失去对新模型的独立评价资格；新模型需要尚未进入训练的独立证据，不得沿用旧报告作最终证明。
