## 三段式路由

冻结模型输出 `p_unrelated`。完整路由覆盖所有未有人工作答的记录：

| 条件 | 动作 |
|---|---|
| `p_unrelated <= T_keep` | `auto_keep` |
| `T_keep < p_unrelated < T_exclude` | `manual_review` |
| `p_unrelated >= T_exclude` | `auto_exclude` |

“100%覆盖”指每条记录均进入上述三个动作之一，不等于100%自动处理。自动覆盖率是 `auto_keep + auto_exclude` 的人口比例；人工率是 `manual_review` 的人口比例。Qwen、`T_keep=0.14`、`T_exclude=0.86` 是已完成检验的冻结策略身份；锁定测试判为 `FAILED_MANUAL_ONLY`，因此该三段动作不能作为正式自动路由执行，未有人工作答的记录当前全部转人工。
