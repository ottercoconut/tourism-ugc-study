## 三段式路由

冻结模型输出 `p_unrelated`。完整路由覆盖所有未有人工作答的记录：

| 条件 | 动作 |
|---|---|
| `p_unrelated <= T_keep` | `auto_keep` |
| `T_keep < p_unrelated < T_exclude` | `manual_review` |
| `p_unrelated >= T_exclude` | `auto_exclude` |

“100%覆盖”指每条记录均进入上述三个动作之一，不等于100%自动处理。自动覆盖率是 `auto_keep + auto_exclude` 的人口比例之和；人工率是 `manual_review` 的人口比例。旧Qwen、`T_keep=0.14`、`T_exclude=0.86` 的锁定测试判为 `FAILED_MANUAL_ONLY`，该历史策略不得执行。新周期的融合模型与0.44/0.96策略已按独立盲审只放行 `auto_exclude`；`auto_keep` 及中间带均进入人工。
