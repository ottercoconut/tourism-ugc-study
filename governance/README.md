# 数据治理

本目录记录伦理、隐私、版权、平台条款和公开发布决策。

当前文件较少，统一平铺并使用明确文件名：`license-strategy.md` 记录许可边界，`release-checklist.md` 记录公开前检查。伦理、隐私、保存期限或平台条款文件在实际形成时直接加入本目录；文件增多后再分类。

`research-data-freezes.json`是无UGC的冻结登记，当前身份`research-data-20260912`。
它绑定私有manifest SHA、汇总数量、封存代码和时间；正文、作者身份、媒体路径明细
及全文件清单只留Git忽略目录。原始内容/图片和清洗候选已经保护，最终人工研究集
尚未发布。见[冻结决定](../docs/decisions/2026-09-12-原始抓取集与清洗候选冻结.md)
与[校验协议](../docs/protocols/研究数据冻结与校验.md)。

内部冻结不等于公开许可、永久保存授权或异地备份。未来需纠错或移除材料时，先由
研究者明确授权并记录受影响身份与原因，不通过普通缓存清理隐式销毁冻结资产。

UGC 可公开访问不等于可以重新分发。任何含原文、图片或作者信息的数据发布必须单独审查。
