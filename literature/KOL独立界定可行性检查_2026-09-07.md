# KOL 独立界定可行性检查

日期：2026-09-07。性质：独立审查建议，未修改现行研究设计、编码标准或操作协议。沿用前次文献核读，补充定向原始研究与出版页面核验，并重新运行本地研究切片的只读覆盖审计。

## 1. 判断

**KOL 可以在不设置 KOC 对照类别的情况下独立成为研究对象。但目前不能把现有 EA 标签改名为 KOL，也不能直接宣布现库已经识别出足够的 KOL。**

保留主题有一条可行的设计方向：明确采用“旅游领域社交媒体影响者”的研究操作定义，先据独立的作者与受众材料建立样本，再比较这些创作者的旅游内容表达。取消 KOC 对立分类，不要求所有入选者没有消费经验，也不强制入选者具备职业资格。

这是一项有条件的研究设计选择，不等于已经验证了每名作者对受众的实际影响。若论文坚持测量严格意义上的意见领导、说服效果或决策影响，则现有材料不足。

## 2. 文献依据与适用边界

| 证据 | 本次核验位置 | 对独立界定的意义 | 不能推出什么 |
|---|---|---|---|
| Casaló、Flavián 与 Ibáñez-Sánchez（2020） | 出版页面摘要、引言；前次已核验，今次复核 | 研究 Instagram 受众感知意见领导，不以 KOC 为必要对照，说明该问题能独立研究 | 其受众感知不能从我们的作者简介直接填出 |
| Enke 与 Borchers（2019） | 出版页面摘要与题录；未取得全文核读 | 从内容生产、传播、互动及与相关受众形成的关系界定社交媒体影响者 | 不提供适用于青岛 UGC 的统一粉丝门槛，也不能证明 influencer 与所有语境下的 KOL 完全同义 |
| Dorta-Preen 与 Santana-Talavera（2025） | 已有全文 §3，本次重读 | 旅游内容分析可以按公开资料及粉丝规模选择影响者样本，并研究内部类型差异 | 这是样本操作化先例，不是已验证的意见领导诊断工具 |
| Cha 等（2010） | 已有全文 Conclusions | 关注者规模与转发、提及代表的影响并不等价 | 不能把任何粉丝阈值说成识别真实意见领导的金标准 |
| Hughes 等（2019） | 已有接受稿中的 Blogger expertise 测量 | 专业资历和受众规模可以作为不同变量处理 | 专业性指标本身不是 KOL 身份标签 |
| Harrigan 等（2021） | 西澳大学机构库题录及摘要；未核读全文 | 公开社交数据识别市场通晓者的研究使用了自陈调查作为另一类证据；提醒我们区分预测特征与构念测量 | 不可直接把其 Twitter 指标迁移到旅游 KOL，更不能忽略其调查环节 |

来源：[Casaló 等](https://www.sciencedirect.com/science/article/pii/S0148296318303187)、[Enke 与 Borchers](https://www.tandfonline.com/doi/abs/10.1080/1553118X.2019.1620234)、[Dorta-Preen 与 Santana-Talavera](https://doi.org/10.3390/urbansci9070262)、[Cha 等](https://doi.org/10.1609/icwsm.v4i1.14033)、[Hughes 等](https://doi.org/10.1177/0022242919854374)、[Harrigan 等的机构库记录](https://research-repository.uwa.edu.au/en/publications/identifying-influencers-on-social-media/)。

核验范围内可见两种路径：受众或关系层面的意见领导测量，以及根据公开指标选取影响者的内容研究。两者都可以研究，但必须说明选用哪一种，不能把第二种的纳入结果表述为第一种的测量结果。部分出版社直接打开受限；相应结论仅使用可访问的出版社搜索页面内容、机构库摘要或既有本地全文，不冒充已完成新增全文核读。

## 4. 可以保留 KOL 主题的最简识别方案

建议的研究操作定义草案：

> 本研究将旅游领域 KOL 操作化为在公开社交平台持续发布旅游相关内容、面向超出私人关系的可观察受众进行传播的个人创作者，并以预先规定的领域活动与受众规模标准建立研究样本。该定义用于界定旅行社交媒体影响者样本，不作为实际说服效果、受众信任或商业身份的测量。

这是**待讨论、待校准的研究定义**。“超出私人关系”不能仅靠主页自称判断，需要公开受众指标或可审计的外部材料支持。相关阈值尚未确定；此处不设置任意数字制造现库已可直接执行的印象。

具体分为两层：

**第一层：样本纳入。** 检查个人主体、稳定账号、持续旅游内容、公开受众规模及取证时间。粉丝数与旅游活动合用形成受限样本；不能把高粉丝、专业认证或一次爆款任一项单独设为充分条件。可靠的领域影响者名录或特定平台创作者资质若已有，可辅助核查，但不把泛认证等同于影响力，也不要求所有人都有商业合作。

**第二层：入选后的特征编码。** EA 与 CE 用来描述样本内部差异，不再负责决定谁是 KOL。入选者可以有旅行经验表达、同伴导向，也可以没有职业资格；CE=1 不排除入选，EA=1 也不保证入选。这样才真正取消 KOL／KOC 的对立。

建议预先约定样本材料中“旅游相关”与“以旅游为持续主线”的区别。若选择后者，研究总体将收窄为旅行影响者，生活方式影响者偶尔谈青岛的内容不再自动属于同一总体。

### 粉丝数在这里为何可以使用

原方案把角色与规模分开，是为了不把规模误当成社会身份。新的方案可以把规模作为公开影响者样本的**纳入代理标准**，但必须承认研究对象被它限制了。该调整不是恢复“高粉=真实 KOL、低粉=KOC”的旧规则。

具体阈值需依据所采用的影响者定义及平台语境预先确定，并对邻近阈值检查结论稳定性；不能从当前分布里选择最能产生显著差异的数字。当前研究结果也不得反过来参与纳入判断。

**不必为了研究 KOL 的内容，先为每个人完成因果影响实验。** 但必须区分“符合本研究影响者样本标准”和“已证明改变受众态度或行为”，论文只能作前一种声明。

## 5. 减少的工作与保留下来的工作

| 工作 | 变化 |
|---|---|
| 区分 KOL 与 KOC 的概念论证 | 明显减少，不再建立互斥类型 |
| 处理 EA／CE 同时阳性的身份归属争议 | 明显减少，两维可以共存 |
| 逐项证明 KOL 缺少经验同伴导向 | 取消此类排除要求 |
| 为每位作者核对专业学历、职业、机构资历以决定是否入选 | 不再是普遍必需；是否保留 EA 取决于后续研究问题 |
| 个人主体、稳定账号与持续旅游内容核查 | 保留 |
| 受众规模及其时间、来源核查 | 成为样本纳入的重要工作，不能省略 |
| 证明每位作者的真实影响、信任或商业身份 | 本方案不作这些测量主张，故不要求为这些主张追加数据 |
| 编码一致性、样本可比性、目标内容与纳入证据隔离 | 保留 |

因此，**减负主要发生在分类与理论解释上；身份简介要求可降低，但作者历史和受众资料要求不会一起消失。** 具体能节省多少人时须通过校准记录，不能根据文件变少就估算。

## 6. 对论文主线的影响及建议

可以保留“KOL 的旅游目的地形象表达”这一方向，取消“KOL 与 KOC 的比较”以及依赖该二分的假设。新的比较可以是入选影响者内部的平台、受众规模或预先选定的创作者特征差异；不应一次加入全部维度而重新增加复杂度。

只有研究样本真正按此标准建立，正文结果也围绕该样本展开时，才宜继续让 KOL 居于标题核心。如果主结果依然覆盖所有个人旅游 UGC，而只有少量作者符合影响者标准，KOL 应作为子样本分析，不能用标题概括整个五平台总体。

**建议：保留 KOL 主线作为条件性方案，优先做小红书样本的可执行性核查，不立即转为一般创作者研究，也不直接冻结新的 KOL 标签。** 当前检查已确认概念上可独立、操作上有先例；尚未确认具体纳入门槛、时间条件和最终样本支持。

在正式采用前，需确定本文所用 KOL 与旅行社交媒体影响者的关系及受限解释，选定纳入规则，复用现有校准材料检查执行与候选支持，再同步更新规范、操作协议、研究问题和假设。旧协议里的 KOL／KOC 各至少 10 名等门槛不能直接搬到新设计；它们也不会因本报告而自动废止。
